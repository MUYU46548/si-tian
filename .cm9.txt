fix(system3d): 两颗行星同轨（用户指出）+ 锯齿模糊 + 小行星带铺满整片

## 1. 两颗行星在同一条轨道上 —— 用户指出，确实不合理

根因：3D 借用了 2D 的 `planetOrbitLayout`，而它是
`orbit = floor(pIdx / 3) + 1` —— **每 3 颗行星共享一条轨道**、靠角度错开。
这在俯视平面图上合理（避免图标重叠），放到 3D 就是"两颗行星同轨并行"。
曜川星系只有 2 颗行星，于是都落在第 1 圈。

改法：**只给 3D 一条独立规则** `orbitRadius3dByIndex(index)` —— 一圈一颗、等差。
没有改 `systemOrbit.js`，因为它被 2D 的 SystemView / SystemDetailView 共用（7 处引用），
改了会连 2D 布局一起变（越界）。这是两条视图本来就不同的需求。

新判据 a2b：任意两颗行星轨道半径必须不同，且必须从 orbitBase 起按 orbitStep 等差（不漏圈）。
反向探针：换回按 2D orbitRadius 算，这条必红。

## 2. 锯齿 + 模糊

用户原话：「这版锯齿感非常强，但是完全没有像素游戏的美感，只让人觉得模糊。」
"又锯齿又模糊"是两个独立成因同时发生：

| 成因 | 改前 | 改后 |
|---|---|---|
| MSAA 关着 | `antialias: false` | **true** |
| 球段数不足（近景看得出多边形棱） | 行星 24×16、恒星 28×20 | 行星 **40×28**、恒星 **48×32** |
| 光晕贴图放大 2.4 倍 | 128×128 | **512×512** + mipmap |
| 像素比上限 | 1.5（细线落半像素） | **2** |
| 轨道线太淡像断线 | opacity 0.32 / #4a5a78 | **0.5 / #6d84a8** |

`antialias:false` 是 2026-10-28 按"低配观感"定的，但**单星系是近景主视图**，
球面/细线/文字全是高对比边缘 —— 那个取舍在远景总览里成立，在这里不成立。
低配兜底仍在：qualityLevel 自动降档会先压 pixelRatioCap。

## 3. 小行星带铺满整片（修 1、2 之后才暴露）

原来带子铺在 `min(orbit)+1.6 ~ max(orbit)-1.2`，即**跨越所有行星轨道**。
2 颗行星时那是 8.6~13.2 的整片环域，720 个点撒两圈之间 → 看起来是"满天碎屑"。
（它此前一直被"行星挤在同一圈"遮住，轨道拉开后才显形。）

改成**夹在最外两个轨道之间的窄带**（带宽 = 轨道间距的 22%），
点数随带宽走、竖向厚度从 ±0.4 收到 ±0.11、关掉 sizeAttenuation。
