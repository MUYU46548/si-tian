# SiTian 司天 v0.1.3 发布说明

> 本地世界观星图可视化工具 · 面向 Obsidian 知识库的「世界 → 星域 → 恒星系 → 行星 → 区域 → 建筑」七层可编辑地图。
> 本次更新以**稳定性与专业编辑能力**为主：修复了打包发布后的若干关键故障，并补齐了一批面向重度用户的地图编辑工具。

> ⚠️ **下载说明**：Assets 列表中请下载 **`SiTian-Setup-0.1.3.exe`**（约 77 MB）进行安装。`latest.yml` 与 `*.exe.blockmap` 为自动更新配套文件，**无需手动下载、也无法独立运行安装**。

---

## ✨ 新增功能

- **错误边界与友好提示（P0.4）**：渲染进程异常不再白屏，改为弹出友好错误面板（含详情复制 / 提交反馈 / 重新加载入口）；主进程异常经 `electron-log` 落盘，便于排查。
- **克隆 / 复制粘贴（E1）**：支持选中节点或节点组，跨视图复制、粘贴并自动重排，保留层级与样式。
- **可交互撤销历史面板（E2）**：可视化浏览操作历史，点击即可跳转到对应状态，撤销 / 重做更可控。
- **多选对齐与分布（E3）**：选中多个节点后可按顶 / 底 / 左 / 右 / 居中快速对齐，并支持等间距分布。
- **旋转 / 缩放手柄（E4）**：选中对象新增旋转与缩放控制点，支持精确旋转角度与比例缩放。
- **智能参考线（E5）**：拖动时自动吸附到其他节点的中心 / 边缘，并显示对齐辅助线，排版更整齐。
- **批量属性编辑（E7）**：一次修改多个选中节点的共有属性（图层、标签、样式等）。
- **画布内联文本编辑（E9）**：双击文本对象即可就地编辑，无需切换面板。
- **GeoJSON 互操作（E10）**：支持将地图数据导出为 GeoJSON，或从 GeoJSON 导入，便于与外部 GIS 工具联动。
- **状态栏（E11）**：底部状态栏实时显示节点数、坐标、缩放比例与当前工具，操作反馈更即时。
- **工具箱 dock 化（U1）**：工具栏可停靠到画布四周，按工作习惯自由布局。
- **缩放控件（U2）**：独立缩放控件支持适配视图、选中对象适配与百分比缩放。
- **右键上下文菜单统一框架（U3）**：在画布任意位置右键均可唤起与当前对象相关的操作菜单。
- **加载骨架屏（U4）**：数据提取与地图初始化期间显示骨架屏，告别白屏等待。
- **地图坐标系绑定真实距离（7b5d170）**：画布坐标关联实际地理尺度，导出与参考图校准更准确。
- **指北针 / 比例尺（65a1d93 / a1d4b3c）**：编辑与导出均可叠加指北针与比例尺，且可单独开关。
- **海拔 / 气候 / 降水图层（f40a927）**：行星地图新增地形环境图层，配合 InteriorView 参考图移植，地理信息更丰富。
- **导出与批量排列（a1d4b3c）**：导出图件支持指北针 / 比例尺；节点批量排列与形状差异化让地图更清晰。
- **组复制粘贴 / 批量对齐分布 / 文本命中精确化 / 磁吸扩展（2e17f08）**：编辑增强专项收尾，选区操作、磁吸吸附、旋转正文命中等体验优化。

## 🐛 修复

- **打包后 preload 静默不加载（56ab815）**：显式设置 `sandbox: false`，并修正版本号读取方式（改读 asar 内 `package.json`），彻底解决 `sitianAPI` 为 `undefined` 导致功能全部失效的问题。
- **托盘图标空白（56ab815）**：将图标资源纳入打包清单，托盘与菜单现在正确显示 SiTian 图标。
- **关闭行为与卸载退出（56ab815 / C7）**：点 × 默认最小化到托盘并提示去向；新增「关闭时退出应用」开关；卸载流程修正进程退出时序，避免卸载器卡死。
- **preload 版本号恒显示旧值（ff99392）**：修正 `app.getVersion` 在隔离上下文抛错回退硬编码的问题，版本号现正确显示 `0.1.3`。
- **行星切换幽灵选中态 / 放置模式手柄劫持 / 批量面板与侧栏重叠（365b14b）**：三处交互回归修复。
- **程序图标重制（a13fb1d / 247fbda / ba71432 / 112bd91）**：去除白边、全尺寸覆盖、恢复浅色背景、加大网格与节点消除视觉瑕疵。

## 📦 安装与升级

### 全新安装
1. 在下方 **Assets** 区域下载 `SiTian Setup 0.1.3.exe`（约 77 MB）。
2. 双击运行，选择安装路径（默认 `C:\Program Files\SiTian`），建议勾选「创建桌面快捷方式」。
3. 首次启动会弹出引导：点击「选择 Obsidian 知识库」→ 选中你的库文件夹（需含 `.obsidian`，如 `E:\图书馆\ROSA`）→ 自动提取数据。
4. 提取完成后即可浏览七层世界观星图。

### 从旧版本升级
- **自动更新**：启动时会后台检查更新；也可通过「托盘右键 → 检查更新」或「关于面板 → 检查更新」手动触发，下载完成后重启即升级。
- **手动升级**：直接运行新安装包覆盖安装即可，你的缓存与配置会保留。

### 卸载
- 「设置面板 → 数据管理」或「Windows 设置 → 应用 → SiTian → 卸载」；托盘菜单「退出」后亦可正常卸载。

## ❓ 常见问题

**Q：Windows 提示「Windows 已保护你的电脑」？**
A：新发布应用尚未积累足够信誉，属正常现象。点击「更多信息」→「仍要运行」即可。

**Q：没有 Obsidian 知识库能试用吗？**
A：SiTian 以 Obsidian 库为唯一事实源。首次启动需选择一个含 `.obsidian` 的库目录；非 Obsidian 目录会给出明确提示，不会白屏或崩溃。
