# Emoji → 矢量图标 选型调研（批次 A8）

> 生成时间：2026-08-22 ｜ 性质：**调研 + 选型结论，本批次不实装**（HANDOFF A8 明确"只做调研 + 选型，不强制替换"）。

---

## 1. 现状盘点

- 全渲染层 emoji 图标约 **160 处**，分布：PlanetMap(44) / InteriorView(19) / AreaMap(19) / ObjectListPanel(14) / NodeDetailPanel(11) / AboutPanel(7) / SettingsPanel(6) / App.vue 工具栏(6) / ChangeLog(5) / SystemDetailView(4) / 其余散布约 20 文件。
- **两类载体**：
  1. **DOM 文本**（按钮/标题/tab 内联 emoji）——占绝对多数。问题：跨平台字形差异（Windows Segoe Emoji vs macOS Apple Color Emoji 大小基线不一）、彩色 emoji 无法跟随明暗主题、缩放发虚。
  2. **Canvas fillText**（仅 2 处：AreaMap 标记图标 `marker.icon || '📍'`、planetDrawing 锁定角标 `'🔒'`）——同上，且在高 DPI 下更明显。
- 已有可复用的矢量先例：`EagleEye`/树导航的**层级圆点**是 CSS/canvas 画的纯色圆（非 emoji）；`PanelShell` 的折叠/关闭按钮是文本字符（▸/×）。

## 2. 候选方案对比

| 方案 | 一致性 | 主题适配 | 体积/构建 | 迁移成本 | 备注 |
|---|---|---|---|---|---|
| A. 手写内联 SVG 组件 | ★★★ 完全可控 | ★★★ `currentColor` 直通令牌 | 零依赖 | **高**（每个图标手写/搬运 path） | 适合品牌专属图标，通用图标不划算 |
| B. `lucide-vue-next`（Vue 组件库直引） | ★★★ | ★★★（stroke=currentColor） | tree-shaking 按需，~0 冗余 | 低 | ISC 许可，1400+ 线性图标，风格统一细腻 |
| C. `@iconify/vue`（运行时按需） | ★★★ | ★★★ | 运行时取图标（可离线打包集合） | 低 | 首帧可能闪（图标异步到达） |
| D. icon font（FontAwesome/Material） | ★★ | ★★（需多套字体色） | 字体文件大、加载闪烁 | 中 | 与"拉伸不变形"目标背道而驰，排除 |
| **E. `unplugin-icons` + Iconify 图标集（推荐）** | ★★★ | ★★★ | **编译期**内联为 Vue 组件，零运行时 | 低 | Vite 5 兼容；`~icons/lucide/star` 语法按需引入任意集合；可配 `customizations` 强制 `currentColor` |

## 3. 选型结论

**推荐方案 E：`unplugin-icons` + `lucide` 图标集（线性风格）**，理由：

1. **编译期内联**：与现有 Vite 5 构建零摩擦，产物是纯 SVG 组件，无运行时请求、无字体闪烁。
2. **`currentColor` 直通设计令牌**：`color: var(--text-tertiary)` 一处生效，明暗主题（A6 刚统一的令牌体系）自动适配——彩色 emoji 做不到。
3. **拉伸不变形**：SVG `viewBox` 缩放天然无损；统一 24×24 网格 + 线性描边，与现有 UI 密度匹配（按 `width/height: 14–16px` 使用）。
4. **渐进迁移友好**：新旧图标可共存（emoji → `<IconXxx>` 逐个替换），不需要一次性大改。

**备选 B**（直接依赖 lucide-vue-next）：若不想引入 vite 插件，功能等价，只是少了按需裁剪的编译期保障（lucide 本身 tree-shaking 也够好）。**排除 D**（icon font）与纯手写 A（工作量不成比例）。

### Canvas 内 emoji 的处理

两处 `fillText` emoji 不适合直接换 Vue 组件。方案：**预渲染 SVG → offscreen canvas 位图缓存**（`composables/textures.js` 已有 createOffscreenCanvas + 缓存的成熟模式，照搬即可）：启动/首次绘制时把 🔒 等少量图标 SVG 光栅化为 icon atlas，绘制时 `drawImage`。DPI 缩放下按 `devicePixelRatio` 生成对应分辨率。

## 4. 建议迁移顺序（供实装批次参考）

1. **第一批（高频可见）**：App.vue 工具栏 6 个按钮 + 面板 header（设置/关于/快捷键/变更日志标题 icon）。
2. **第二批**：编辑工具栏（PlanetMap/AreaMap/InteriorView 的工具按钮 ~30 处）——tooltip 文案保留中文，图标换线性 SVG。
3. **第三批**：树/详情面板/列表内的小图标（ObjectListPanel/NodeDetailPanel）。
4. **第四批（最后）**：canvas 内 2 处 fillText → SVG 光栅化 atlas。
5. **不迁移**：层级调色板颜色（TreeItem 圆点、getNodeColor）——它们本来就是矢量色块，不是 emoji。

**工作量估算**：第一批 ~0.5 天、第二批 ~1 天、第三批 ~1 天、第四批 ~0.5 天，每批独立可验收（build + test + 双主题截图比对）。

## 5. 验收标准（实装时）

- 任意缩放（浏览器 zoom 50%–200%）图标无发虚/变形（viewBox 保持）；
- 明暗两主题下图标颜色跟随文字令牌（无彩色残留）；
- `npm run build` 产物包含全部所引图标（无运行时 404/闪烁）；
- 15+ 回归用例全绿（工具按钮 title/选择器不变，仅视觉元素替换）。
