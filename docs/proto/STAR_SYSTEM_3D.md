# 单星系 3D：现状 vs 群星参考图（2026-11-25）

> 用户 2026-11-25："**单星系内部本来就是我要的**"。
> 星域级 3D 已停止（见 `DOMAIN3D_PROTO_RESULT.md`）；
> 单星系 3D 是**2D 表达不了**的那一类，值得投入。

## 现状（真机截图）

`python scripts/proto/shot_system3d.py` → `build/system3d/system3d-current.png`

恒星系"曜川星系"：1 颗恒星 + 2 颗行星（沙漠星球 / 草原星球），
恒星有光晕与纹理、行星有球面明暗与地表纹理、椭圆轨道、星名标签、60fps。

**这个底子不差** —— 它是 2026-10-28 交付的 `System3DView.vue`（33 KB），

## 与群星（`refs/src/星系视图1.png`）的差距

| 项 | 群星（量的） | 司天现在 | 差多少 |
|---|---|---|---|
| **轨道** | **多圈细虚线**（内圈到外圈十几条，每圈是一条独立的淡虚线） | **只有 1 条实线椭圆** | **最明显的一条** |
| 恒星 | 小而亮，强烈日冕，中心过曝 | 大而暗，光晕偏散 | 恒星偏大、偏暗 |
| 行星 | 小圆盘，明显**小于**恒星 | 与恒星比例接近 | 行星偏大 |
| 背景 | 星云 + 尘埃带 + 密集星场 + 远景点缀 | 只有稀疏散点 | 缺整层 |
| **小行星带** | 有（一段虚线环） | 无 | 缺 |
| 星系名 | 底部横幅 + 状态条 | 顶部小字 | 位置不同 |
| 星区名 | 斜体、字距大、低饱和 | 无 | 缺 |

## 优先级（按"改起来的性价比 × 观感影响"）

1. **轨道**：多圈细虚线 —— 一条改动，观感提升最大。群星的轨道是**每颗行星一圈**，
   现在的实现似乎只画了最外那一圈（或所有行星共用一条），这是最该修的。
2. **从大气层感（atmosphere rim）**：群星行星边缘有一圈发光大气，
   现在行星是硬边球。加一层 fresnel shader 或简单的外描边即可。
3. **小行星带**：一段虚线环 + 一堆小点，廉价但观感加分。
4. **背景**：可复用星域原型里的那套（星场 + 星云），代码现成。
5. 恒星亮度/大小、行星比例：微调参数。

## 已确认可复用的东西

- 星域原型里的背景三层（星场 / 星云 / 亮核）—— `scripts/proto/domain3d-proto.html#buildBackground`
- 正交投影那条结论**不适用这里**：单星系内部要透视（有纵深感才像在飞），
  群星的单星系视图也是透视（近大远小明显）
- `sizeAttenuation` 陷阱同样适用

## ⚠️ 一条重要的判断

**星域级 3D 失败的原因不是"3D 不行"，而是"那一层 2D 已经好看"。**
单星系内部不同：2D 的轨道图表达不了"行星在三维空间里绕转、有日照面、有大气"。
所以这里值得投，而且**不需要和 2D 比"谁好看"** —— 它是补充，不是替代。
