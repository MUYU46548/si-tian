## 0. 复现方式（三条命令）

```
python scripts/tests/tools/_lab.py up                       # 注入 mock + 起 Vite(5180) + Edge
python scripts/tests/tools/_lab.py run scripts/tests/tools/_shot01_handriver_node_dots.js
node   scripts/tests/tools/_shot_save.js 01                 # 把 lab-shot.png 存成 01-…png
python scripts/tests/tools/_lab.py down                     # 收尾（必做）
```

* `_shot_save.js` 存在的理由：交付图文件名是中文，而项目纪律**禁止用 shell 读写含非 ASCII 的文件**；
  中文名写在那个 JS 文件里（UTF-8 源码），命令行只传 ASCII 序号。
  ⚠️ 每跑完一个探针**立刻存图**，否则下一张会覆盖 `docs/assets/lab-shot.png`。
* 探针里的截图前置动作（踩过的坑，全部已固化进探针）：
  ① 用 `document.elementFromPoint` 逐点找出盖住画布的浮层并 `display:none`；
  ② 截图前 `sc.render()` 再 `await` 一拍（否则截到的是上一帧）。

### 共用合成地形（6 张**同一份**）

`labShotMound`：圆丘高度图 **121×121 / spacing 20**（`h = clamp(90 − d×1.1)`，d = 到中心格的距离），
中心世界坐标 `(−800, −800)`；陆地掩膜 = **半径 63.6 格 ≈ 1272 世界单位**的圆（正是 `h = 20` 的等值线，
所以"掩膜判陆"与"高度判陆"在这份合成地形上同形，不会出现幻影格）；`rasterLayer = 'none'`
（去掉 landsea 底噪，也避免海色 `#c9d6e4` 被河色分类器误判）。

01 / 06 在这一份底图上**显式清空自动河**（`autoRivers=[] / autoRiverSegments=[]`）—— 那两张只讲手画河。

## 2. `02-自动河-剪枝前.png`

**要证明**：不剪枝时，自动河网 = **一整片平行斜线网格**（每格一根小棍），与 03 并排看差异一眼可见。

**探针**：`scripts/tests/tools/_shot02_autoriver_unpruned.js`
**参数**：底图 `labShotMound`；`generateAndShowRivers()`；相机 = 把整幅网格（2400×2400）装进画布（5% 余量）。

**怎么做到"全部段都画"**（两条路都试，据实记录哪条生効）：
1. 任务书那条：`sc.riverFlowGate = () => 0` —— 渲染侧读的可能是 `<script setup>` 闭包里的那个函数，
   覆盖 `setupState` 属性**未必生効**；
2. 保底那条（走产品自己的既有契约）：把每段的 `flow` 清成 `undefined` + 段流量上界清 0 →
   `riverFlowGateByQuantile` 无流量数据返回 0 → `riverFlowGate` 兜底也算不出 → 返回 0 →
   `pruneRiverNetwork(_, 0)` 走 `if (!(th > 0)) { kept = 全部 }` = **不剪枝**。
   ⚠️ 代价：线宽一律落到下限（干流那一档更粗的线没了）。

**数值**

| 项 | 值 |
| --- | --- |
| 段总数 / 裁剪后网络段数 | ⬜ 待填 |
| 真闸门值 / 真剪枝后段数 | ⬜ 待填 |
| 强制手段（`mode`） | ⬜ 待填 |
| `sc.riverFlowGate` 覆盖是否生効 | ⬜ 待填 |
| 强制后闸门值 / 保留下来的段数 / 是否等于全部 | ⬜ 待填 |
| 相机缩放 / 一格屏幕像素 | ⬜ 待填 |
| `riverMinWidthForNet()`（及其乘缩放后的屏幕值） | ⬜ 待填 |
| 河色像素数（真闸门 vs 强制后） | ⬜ 待填 |

**看图要点**：河色铺满全岛，呈布纹/平行斜线网格。

## 5. `05-颜色统一.png`

**要证明**：同一张底图上**同时**画出的**导入河 / 手画河 / 自动河**是同一种蓝（唯一河色 `#5d97bb`），
不再有第二种蓝。

**探针**：`scripts/tests/tools/_shot05_three_rivers_one_color.js`
**参数**：同一份底图；`generateAndShowRivers()` 生成自动河；导入河 `{id:'imported_x', width:0.26, discharge:600}`
（id 不以 `river_` 开头 → 走 `drawRivers`），手画河 `{id:'river_x', width:0.6}`（前缀 `river_` → 走 `drawRiverPaths`）；
相机 `scale = 1.0`，中心 = 流量最大段中点**夹到岛内半径 ≤820**（保证两条手工河都在掩膜里、不被海岸线裁掉）。

**采样分两步**（让"归属"干净）：
* A. 先把自动河藏掉（`autoRivers=[] / autoRiverSegments=[]`）再采 → 这两条河的点上只可能是它们自己的像素；
* B. 恢复自动河，采 5 个自动河段中点 → **在这个状态截图**（三条都在）。
两次采样比的是同一种 `strokeStyle`，所以"同色"结论不受影响。

**数值**（目标色 `#5d97bb` = (93,151,187)）

| 项 | 值 |
| --- | --- |
| 导入河 5 点 RGB / 与目标色的最大通道偏差 | ⬜ 待填 |
| 手画河 5 点 RGB / 偏差 | ⬜ 待填 |
| 自动河 5 点 RGB / 偏差 | ⬜ 待填 |
| 三者中的最大偏差 | ⬜ 待填 |

**判据口径（唯一河色的定义）**：`#5d97bb` 是**唯一**被描边路径使用的河色 ——
`utils/riverRender.js` 的 `BASEMAP_RIVER_COLOR = '#5d97bb'`，`RIVER_DRAW_COLOR = BASEMAP_RIVER_COLOR`
