## 0. 结论（先给数）

同一块陆地轮廓（带波瓣的椭圆）、同一批 seed，v1（旧口径）与 v2（本修）对照：

| 判据 | v1（坡面 + 噪声） | v2（结构地形） | 阈值 |
|---|---|---|---|
| **各向异性**（高频残差结构张量） | 4.4% / 17.8% / 3.7% | **70.1% / 76.3% / 35.3%** | ≥30% 且比 v1 高 15 个点 |
| **主导走向误差**（量出来的 vs 自述） | — | **5° / 12° / 19°** | ≤25° |
| **高原面**（最大连片平高块） | 70 / 20 / 114 格 | **221 / 260 / 470 格** | ≥180 格且 ≥2× v1 |
| **裂谷下切**（走廊带 − 对照带，高度单位） | 2.2 / 0.7 / 0.5 | **8.0 / 12.9 / 6.7** | ≥4 且 v1 <3 |
| **最长主河**（世界单位） | 737 / 870 / 779 | **1645 / 1941 / 1701** | ≥1.3× v1（实测 2.1~2.2×） |
| **汇流上界**（段汇流量） | 430 / 333 / 430 | **1147 / 1073 / 1329** | ≥1.3× v1（实测 2.5~4.0×） |
| 陆地均值高度 / >60 占比 | 46/45/48，7%/11%/20% | 44/42/44，18%/15%/21% | 均值差 ≤8、>60 ≤35% |
| 单次推演耗时 | — | 14~28ms（7081 格） | ≤1500ms |

**一句话**：以前那份是"坡面 + 噪声"，现在这份**有方向、有面、有沟**，而且是**同一个骨架**（离岸距离场 +
洼地填平）上长出来的 —— 河也跟着从"碎支沟"变成"有主干的水系"（最长主河 2.1~2.2 倍）。

判据全部落在 **`scripts/tests/unit/test_terrain_structure.js`**（15 条，含反向对照）。
观感存档：`docs/assets/terrain-structure-20261018/`（v1/v2 的地形图与水系图各一张）。

## 1. 三种结构怎么做出来的（都只用司天自己的东西，不依赖外部数据）

骨架不变（`utils/terrainSynthesis.js` 的离岸距离场 + chamfer 距离变换 + priority-flood 填洼），
在合成高度时叠三样**真实地形成因**：

### ① 山脉走向 —— 各向异性脊线（ridged multifractal）
- 普通 fbm 的等值线是"疙瘩"，做不出"一条山脊"。脊线噪声的标准做法是把噪声折起来
  （`1 - |2n - 1|`）再平方强化、逐八度叠加；
- **唯一的关键是各向异性**：采样时把坐标转到"走向坐标系"，让**垂直走向的频率（8.5）
  远高于沿走向的频率（2.6）** → 等值线被拉成骨状。两者取相等就退化成碎丘（= v1 的老问题）；
- 叠了一条**次走向**（权重 0.12，与主走向夹 65°）：真实造山带很少只有一条方向；
- 走向由 `seed` 决定（`rangeAxisFromSeed`），并叠一层**域扭曲**（`warp 0.16`）让脊线蜿蜒。

### ② 高原面 —— 按分位圈地 + 强混合
- 一块低频场圈出连片区域，区域内高度被强混合（权重 0.92）到同一个面，只留 `0.015` 的残差；
- 🔴 **阈值必须按分位取**（实测教训）：第一版用固定阈值 `smoothstep01(0.50, 0.62, pf)`，
  在这份地形上 **64% 的陆地都落进掩膜** → 陆地中位高度被抬到高原面上 →
  不但判据量不出"高原"，观感上也变成"整张图就是一块高原"。现在取该场自己的 **p62~p80**，
  覆盖比例由构造保证，换高度预算也不会失效。

### ③ 裂谷 —— 线状折线 + 距离剖面
- 1~2 条由 seed 决定的折线，沿线按距离下切（越靠轴越深，`riftDepth 0.26`，半宽 `0.055`）；
- 🔴 **走向必须跟着山脉走**（`axis ± 15°`）：真实裂谷多沿造山带张裂，而且从判据角度也必须这样 ——
  第一版让裂谷自己随机取方向，于是"结构张量量出的主导走向"变成山脉与裂谷的加权平均，
  与 `rangeAxisDeg` 实测能差 **49°**，走向判据直接失效；
- 🔴 **落点必须用"高/长"比**：归一化坐标里 `ny` 只能到 `aspect`，第一版按 `cy=0.5` 放，
  在扁长地形上把裂谷放到了陆地**外面**（实测 seed=23 走廊 0 格）—— 判据量的是空气。

### 高度预算（这条踩过坑，写在代码注释里了）
下游的「源头高度闸门」是**绝对高度**（`TRACE_SOURCE_HEIGHT = 60`）。第一版结构权重
（0.72/0.46 + 高原 0.66）把陆地均值从 **45.6 抬到 63.1** → **85% 的陆格都在闸门之上** →
一点「自动河流」就是 2400 个源头。现在压到与 v1 同量级（均值 42~44、>60 占 15~21%），
这条有判据守（c3）。

## 2. 判据本身踩过的四个坑（都写进用例注释了）

| # | 坑 | 后果 | 修法 |
|---|---|---|---|
| 1 | 各向异性在**原始高度**上算 | "离岸距离场"的放射状梯度把结构张量冲成各向同性；v1 自己也能刷出 17.8% 假各向异性 | 在**高频残差**（h − 5×5 均值）上算，且只取内陆 |
| 2 | 裂谷用"低于邻域 8 单位且连通 ≥40 格" | 裂谷下切是**沿线渐变**的（穿山深、过谷浅）→ 一刀切把浅段切碎 → 假红（实测 0 格） | 改**走廊带 vs 对照带的相对下切**（因果判据） |
| 3 | 高原面判据"平就行" | v1 的缓坡肩也"平"（seed=7 有 70 格连片） | 必须**连片规模**（≥180 格且 ≥2× v1），不写"v1 必须为 0" |
| 4 | 高原面只在"深内陆"扫描 | 高原不一定长在那里（实测 seed=11 假红） | 扫描区放宽到"离海 ≥4 格的全部陆地" |

## 3. 接线与边界

- **默认开**（`opts.structure !== false`）：产品路径（「更多 → 按轮廓生成地形」按钮、
  以及无高度图时「自动河流」的临时推演）拿到的都是结构地形；
- `structure:false` **只给对照组用**（用例靠它证明"结构真的改变了地形"），
  且该口径**不带 `structure` 自述字段**（用例 c5 守：防止对照被误认为结构地形）；
- 回执多一句结构说明（`scenarioEditing.synthesizeBaseMapTerrain`）：
  「…含山脉走向 53° / 裂谷 2 条 / 高原面 1238 格…」——用户看不到就会以为还是老样子；
- **只读推演、不写数据**：仍是纯函数；要不要落库（`commitHeightmap`，一条 undo）由调用方决定；
- **确定性**：同 seed 逐值相同（用例 c2），换 seed 差 56% 的格。

## 4. 据实说的边界（不许夸大）

1. 这几条判据证明的是**结构指标**（方向性 / 连片平坦 / 线状下切）与**排水指标**（最长主河、汇流上界），
   **不等于**"它就像真实地形"。真实感最终要暮雨看图（SVG 已留档）；
2. 结构地形**不是**给导入地图用的：导入地图（Azgaar `.map`）的高度值来自用户数据，
   我们**不动它**（路由层的四个候选已被否定，见上一份文档）；
3. 现在只有"一条主走向 + 一条次走向 + 1~2 条裂谷"这一种构造，**没有**给用户可调参数
   （走向/高原高度都从 seed 推）。要做"手调地形风格"是另一件活。
