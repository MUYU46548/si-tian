## 1. 本轮唯一的产品改动：画省份时「预览 = 落库」

### 1.1 断点在哪（读代码定位，不是猜）

| | 松手**前**用户看到的 | 松手**后**真正写进 `terrain[]` 的 |
|---|---|---|
| 形状来源 | `tracePath(c, freeTrace)` = **手迹折线**（每个鼠标采样点连一段） | `simplifyClosedTrace` → `conformToSkeleton`（贴已有省界）→ `withBezierControls` |
| 观感 | 一条跟着手抖的细线 | 一条平滑、可能已经吸到海岸/邻省边界上的闭合地块 |

两条形状**不是同一条** → 松手的一瞬间形状会"跳"。用户看到的只是"笔迹"，不是"你将得到的那块地"——
这正是"描点连线模拟器"的观感来源（而且它还会让人不敢下笔：不知道松手之后会变成什么）。

### 1.2 改法：预览与落库走**同一条几何链**

新增 `freeTraceRing(rawPts, { snap })`（`ScenarioMap.vue`）：
`simplifyClosedTrace` → （可选）`conformToSkeleton` → 返回环。三处共用：
`commitFreeTrace`（画省份）、`commitOutlineTrace`（描轮廓，`snap:false`）、画布预览。

预览现在画**两样东西**：
1. **手感线**（细、淡、逐帧跟手）——"我的笔在哪"；
2. **将要落库的地块**（闭合 + 同一套贝塞尔控制点 + 半透明填充 + 实色描边）——"我松开手会得到什么"。

两条实现约束（都很要紧）：
- 骨架**按 `terrain` 引用缓存**（`skeletonForTerrain`）：`buildSkeleton` 在 200~415 省底图上是重活，每帧重建会拖死拖笔；
- 预览形状**按 60ms 节流**（贴骨架是 O(点数 × 骨架点数)）：手感线仍逐帧，只有"地块形状"约 16fps。

### 1.3 判据（`test_113_draw_preview_wysiwyg.py`，全部走真鼠标事件）

| 判据 | 读数（本轮实测） |
|---|---|
| 拖笔期间圈内**被着色**（证明看到的是地块，不是一条线） | 形心像素 Δ = **71**（阈值 >6） |
| **预览环 == 落库环**（逐点） | 15 点 vs 15 点，**逐点相同** |
| 落库环**真的简化**了（不是逐点连线） | 手迹 91 点 → 落库 15 点 |
| 落库环带**贝塞尔**控制点（曲线观感） | 15/15 点都有 |
| 源码闸门 | 预览/落库都走 `freeTraceRing`；预告形状走 `previewTraceRing()` + `withBezierControls`；骨架缓存在场 |
| 回归随动 | `test_63`（自由绘制/Shift 旁路）的源码闸门跟着实现位置更新语义不变：**9 项全过**，Shift 仍共用 0 顶点、不按 Shift 共用 2 顶点 |

## 3. 关于"抄现成产品"

我按你发的参考图（EU4 的省份面 + 那张意大利地形图）对了一遍**现有能力**，逐条说清楚哪些已经是"现成产品那样"、哪些还不是：

| 参考图里的东西 | 司天现状 |
|---|---|
| 省份是**不规则的有机多边形**，边界平滑 | ✅ 手绘环带贝塞尔控制点（本轮又把预览对齐了）；导入的 `.map` 省份本来就是 FMG 生成的自然轮廓 |
| **沿着海岸/邻省边界画**，不留缝不压叠 | ✅ 自由绘制抬手自动贴共享边界骨架（Shift 旁路）；顶点编辑时邻省共边跟着走 |
| **批量填色 / 取消 / 无主地** | ✅ 势力油漆桶 + Ctrl 多选批量指派 + 清空归属（删键，不是置空） |
| 缩放**不糊脸**、缩小有**大字** | ✅ 你说过没问题，本轮没动 |
| **气候 / 产物** | ❌ 还没有（数据模型里没有这两个通道；高度图已有 temp/prec 两个派生档可作前置） |
| 地形起伏观感（山体阴影 / 分层设色） | ⚠️ 有（`terrainShade` 默认关 + 海拔分层设色），但真实底图是 133×75 粗网格，起伏只能这么"糊" |

如果下一轮还要往"更像现成产品"走，我建议按这个顺序（**都能量出判据**）：
1. **省份轮廓的手感再进一步**：现在松手才定型，可以做成"笔到之处边界就跟到"，并给一个可调的"磁吸强度"；
2. **沿地形特征画省界**（河流/山脊当参考线吸附）—— 你发的意大利图里，省界大量沿河、沿山脊走；
3. **气候/产物通道**（数据模型 + 笔刷 + 图例），这是"后续"那一层，得先定数据。
