## 2. 不变量（test_147_basemap_invariants）

已落地并跑绿：

- 指纹覆盖：`terrain`（id/kind/name/顶点）、`heightmap`（h/temp/prec/biome/culture/religion/grid）、`rivers`、`routes`、`burgs`、`referenceImages`、`landFeatures`。
- **正向对照**：高度笔 / 加河 → 指纹必变；undo → 逐字节回基线（证明指纹有判别力）。
- **剧本侧 8 步**：改归属、批量归属、改剧本名、加地名、加标记、建剧本集、移组、存盘 —— 每一步后指纹都 == 基线。
- 失败会点名「哪一步 + 哪类底图数据变了」。

> 该用例只守**数据**；「底图工具只在底图编辑模式出现」由 test_120 守。
