# 拆件索引（Component Disassembly Index）

> **用途**：本项目后期要拆进更大的项目。这份索引记录"每一件在哪、接口是什么、被谁盖着、搬走要注意什么"，
> 趁实现代码还在执行 AI 的上下文里写掉，省得日后考古。
> **基线**：112/112 测试全绿（2026-10-25，P0-P3 完成后）。测试名即验收锚点，拆动任何一件前先看它的测试。

---

## 一、拆件总原则（先读）

1. **依赖方向单向**：`core ← render ← app`，`core ← electron`。core 是零依赖纯 TS（连 `console` 都没用），
   任何 core 文件可以整文件拷走。render 只依赖 core + 浏览器 Canvas API。app 依赖两者 + Vue。
2. **数据契约是接缝**：`GalaxyDoc`（`core/model.ts`）是所有件之间的通用语言。大项目接入时，
   只要能产出/消费这个 JSON 结构，任何一件都可以替换重写。
3. **命令是唯一写通道**：所有文档变更必须走 `core/commands.ts` 的 Command（do/undo/label）。
   大项目若换 UI 框架，只要保住这条，撤销/锁定/原子性全部免费继承。
4. **红线随件走**：字段名不改（`shape` 是唯一追加的可选字段）、core 不碰 DOM、生成器禁 Math.random、
   同 seed 必复现。见 `tests/core-purity.test.ts`（静态扫描会拦住违规）。

## 二、core 层（`src/core/`，纯 TS，零 DOM/Vue/Electron）

### model.ts —— 数据契约 + 类型注册表
- **接口**：`GalaxyDoc / GalaxyNode / GalaxyEdge / Region / GeneratorParams`；`WORLD`（世界尺寸 1600×1000）；
  `FORMAT_VERSION=1`；`edgePairKey(from,to)`（无向边规范化 key）；`NODE_TYPES / EDGE_TYPES`（类型注册表，
  UI 下拉与图例共用）；`createEmptyDoc()` / `defaultGeneratorParams()`。
- **测试**：`serializer.test.ts`（契约往返）、`commands.test.ts`。
- **拆件注意**：`GeneratorParams.shape?: 'disc'|'spiral'|'ring'` 是唯一追加字段（P2），序列化按"缺省不写出"处理，
  旧档字节不变。大项目加字段请照此模式：可选 + 缺省不写 + parse 时校验枚举。

### prng.ts —— 确定性随机源
- **接口**：`mulberry32(seed)`；`Rng` 类（next/range/int/pick/gauss/shuffle）。
- **测试**：间接被 `generator.test.ts`（同 seed 逐字符复现）盖死。
- **拆件注意**：任何想"生成"的件都从这里注入随机性，禁止 Math.random（`core-purity.test.ts` + M2 复现测试双守）。

### ids.ts —— id 分配器（永不复用）
- **接口**：`createIdAllocator(existingIds)` → `{ next('n'|'e'|'r'), observe(id) }`。
- **机制**：会话内单调计数器，冷启动从现存最大编号+1 起步，撤销不回退。
- **测试**：`commands.test.ts`「id 永不复用」。
- **拆件注意**：不持久化计数器——依赖"重开应用撤销栈为空"这一事实。若大项目要跨会话撤销，需持久化。

### geometry.ts —— 边界几何（纯数学）
- **接口**：`buildUnionField(points, radius, opts)`（软并集场 Σexp(-d/τ)）；`marchingSquares(field, level)`（等值线提取，
  网格边交点缓存保证缝合闭合）；`chaikinClosed(pts, iters)`；`polygonArea / polygonCentroid / dist`。
- **测试**：`geometry.test.ts`（单环面积≈πR²、双成员融合、远距飞地、闭合性、Chaikin 切角）。
- **拆件注意**：通用几何件，任何"等值线轮廓"需求可直接搬。P0 后势力轮廓已不走 buildUnionField
  （见 territory.ts 的 φ 场），但此件保留（未来星云边界/其他 soft-blob 需求可用）。

### territory.ts —— 势力归属与所有权场（P0 核心，最值得整体拆走的一件）
- **接口**：
  - `growRegions(nodes, factionCount, weights, rng, interiorRho, rootRhoMax)`：Prim 式区域生长（加权 claim），
    返回 `factionOf: Map<nodeId, faction>` + 根列表。K≥6 时权重前二的势力各多一个根（多核心）。
  - `factionWeights(K, rng)`：每势力 [0.8,1.35] 的权重（大树压境）。
  - `effectiveDistance(input, faction, p)` / `ownershipGap(input, faction, p)` / `wobbleAt / wobbleFade`：
    所有权场 φᵢ(p)=min(claimMax, min_{j≠i} effDⱼ) − effDᵢ 的数学件。
- **两条代数性质（拆件的灵魂）**：argmin 互斥 ⇒ 各势力 φ>0 区域**两两不相交**（零重叠）；
  成员处 effD_own=0 ⇒ **自己的色块必含自己**（数据/渲染永不失配）。测试固化于 `territory.test.ts`。
- **测试**：`territory.test.ts`（自洽/互斥/贴合中点/生长确定性/腹地全覆盖）。
- **拆件注意**：wobble 是 3 组低频正弦（波长 400-800），salt 取文档 seed——想换边界风格只动这个函数。
  INTERIOR_RHO（0.7）/ROOT_RHO_MAX（0.45）两个常数在 generator.ts 导出，测试与渲染同源引用。

### topology.ts —— 航道网络（稀疏化管线）
- **接口**：`buildLanes(nodes, {edgeRule, edgeDegreeCap}, rng)` → `{pairs, report}`。
  管线 = 候选边（knn：k=round(cap/2)-1 ∈[2,cap]；degree：Gabriel 图，天然平面）→ 按长度贪心 + 双侧度上限 →
  2 跳成环（带"不与既有边交叉"检查，loopBudget=n/6）→ 跨分量最短桥接；
  `articulationNodeIds(ids, pairs)`（迭代 Tarjan 割点 = 咽喉要冲）。
- **测试**：`topology.test.ts`（平均度 ≤3.5/零孤点/全连通/成环/0 交叉/长边占比/规范化无重复）。
- **拆件注意**：`pairs` 是 `[fromId, toId]`（from<to 规范化）——渲染层只遍历一遍，结构上杜绝双向重复画线。

### generator.ts —— 参数化生成器
- **接口**：`generateGalaxy(params)` → `{nodes, edges, regions}`（纯函数，自验重试 ≤3 次种子偏移，失败报"参数无解"）；
  `presetParams('A'|'B'|'C')`；`validateParams(params)`；导出常量 `INTERIOR_RHO=0.7`、`ROOT_RHO_MAX=0.45`。
- **流程**（attemptGenerate，改这里之前先读）：撒点（形态模板 disc/spiral/ring + 核密度梯度 + 拒绝采样 minDistance）
  → factionWeights → growRegions（归属）→ buildLanes（先于首府，要度数）→ 首府（度数中心性×100 − 离根距离×0.5）
  → 割点要冲（articulation ∧ degree≥3 → station）→ 资源带（props.rich 按 ρ 三档）→ 命名（后缀按类型分池）
  → 一势力一区。自验：nodeCount 精确 / overlapPairs=0 / maxDegree≤cap / （cap≥3 且 n≥12 时）components=1。
- **测试**：`generator.test.ts`（M2 三组回验 + 敏感性 + 参数无解 + 非法参数）、`faction-layout.test.ts`
  （咬合相邻 ≥3/≥5 对、势力质心 ≤0.5×盘半径）、`territory.test.ts`（生长）。
- **拆件注意**：clusterCount 语义 = 势力数；clusterSpread = 局部弥散抖动；未探索边域（ρ>INTERIOR_RHO）无阵营——
  这是"质心 ≤0.5R"判据在几何上唯一的满足方式（连通到盘缘的区域质心必 ≥0.55R），不是缺陷。

### metrics.ts —— 量化指标（"像不像"变数字）
- **接口**：`computeMetrics(doc)` → `{nodeCount, overlapPairs, avgDegree, maxDegree, clusterShare, components, edgeCount}`；
  `metricRows(doc)` → 指标面板行（actual/target/ok）。注意 clusterShare 分母 = 全部节点，
  未探索边域无阵营 → 求和 = 腹地覆盖率（约 0.55-0.72），不是 1。
- **测试**：`metrics.test.ts`（手工文档逐项算对 + 面板行判定）。

### serializer.ts —— 落盘/读盘唯一通道
- **接口**：`serializeDoc(doc)` / `parseDoc(text)` / `DocParseError`。校验：版本、五类坏文件
  （id 重复/端点不存在/自环/重复边含反向/region 引用缺失）、color 格式、shape 枚举——全部明确中文报错，零静默修复。
- **测试**：`serializer.test.ts`（往返逐字符相同 + 每类坏文件）。
- **拆件注意**：parseDoc 后应立即 `createIdAllocator` 并以此接管 id 分配（commands.replaceDocument 已做）。

### commands.ts —— 命令模式（撤销/重做唯一通道）
- **接口**：`EditorState`（doc/ids/selection/multiNodes/undoStack/redoStack/docRev）；
  `createEditorState / exec / undo / redo / notify`；
  单件命令：`makeAddNode / deleteNodeCommand / moveNodeCommand / updateNodeCommand / makeAddEdge /
  deleteEdgeCommand / updateEdgeCommand / makeAddRegion / deleteRegionCommand / updateRegionCommand /
  toggleRegionMemberCommand / setLockedCommand / generateCommand`；
  **批量命令（P1）**：`deleteNodesCommand`（整批快照去重，undo 按原索引**升序**原位插回——逆序会错位，
  这是踩过的坑，见实现注释）、`moveNodesCommand`（框选拖拽/镜像/旋转的通用底座）、`setRegionMembersCommand`、
  `deleteEdgesCommand`、`mirrorNodesCommand / rotateNodesCommand`（绕质心，内部算 moves 复用 moveNodes）；
  `replaceDocument`（清栈）、`touchModifiedAt`（保存前用，命令本身不碰 meta——否则 do→undo 无法逐字段还原）。
- **关键语义**：锁定只拒生成器（`generateCommand` 工厂抛错）；`MAX_UNDO=100` 截断最老；
  删除节点的 undo 按"原数组索引"升序原位插回（id 不变、顺序也不变）。
- **测试**：`commands.test.ts`（19 例：每种命令 do→undo→serializeDoc 逐字段还原、原子删除、锁定、栈深、批量）。

### view.ts —— 视图状态（.view 文件）
- **接口**：`serializeView / parseView`。缩放/平移不进星系存档。

## 三、render 层（`src/render/`，只依赖 core + Canvas API）

### planetArt.ts —— 行星美术库（方案 C 核心，"类别引用资产"）
- **接口**：`PLANET_CLASSES`（18 类：大陆/海洋/热带/草原/干旱/沙漠/苔原/极地/高山/盖亚/都市/机械/熔岩/荒芜/冰封/剧毒/气态巨行星/冰封巨行星，命名对齐群星天体页）；`getPlanetTexture(classId)`（平面纹理画布，3D 球面贴图用）；`getPlanetSprite(classId, sizePx)`（终止线阴影+大气辉光的 2D sprite，编辑器下钻用）；`getStarGlow(tint, r)`；`planetClassLabel(id)`。
- **机制**：painter 一次成型全局缓存（salt=类别 id 哈希 → 跨会话逐像素一致）；2D/3D 双端共用同一份纹理。
- **测试**：间接（generator 类别分布测试 + 浏览器实拍）。新增类别 = 加一条 def。

### renderer.ts —— 渲染总管
- **职责**：六层管线编排 + 脏标记（sceneDirty/viewDirty，`frame()` 开头判定，不脏直接 return）+ rAF 循环 +
  相机（zoomAtScreen 以鼠标为锚 / panByScreen / fitView）+ 命中测试（pick：节点半径放宽 ≥ 渲染半径，其次边 6px）+
  小地图（paintMinimap / minimapToWorld / centerOn）+ 覆盖层状态（hover/gesture/dragPos/marquee/cutLine）。
- **调试后门**：`window.__renderer`（App onMounted 注入，决策点）——自动化验收借它取节点屏幕坐标。
- **测试**：间接（`view-camera.test.ts` 盖相机数学；渲染本身留验收方实拍）。

### regions.ts —— 势力边界层（所有权场渲染）
- **职责**：`computeRegionShapes(doc, rev, cache)`：以 region.nodeIds 为成员，逐格点算 effD → φ 场 →
  每势力 marching squares(0) + Chaikin → 世界坐标环（按 docRev 缓存，成员不变不重算）；
  claim 半径 = minDistance×2.2（连续分段式，防等值线冲出网格）；星盘椭圆外强制 φ<0；
  `paintRegionFill/Outline`（径向渐隐：腹地浓边疆淡）/`paintRegionLabels`。
- **拆件注意**：单势力文档自动退化为影响域圆盘；用户手工把一个节点划进两个区域时重叠是数据语义（渲染不裁剪）。

### background.ts —— 银河背景资产
- **职责**：`computeBackgroundSpec(seed)`（纯函数：星场三层/星云/尘埃带/深远星系抹痕，全参数预折算）+
  `paintBackground(spec)`（离屏 canvas 一次成型）。每帧只 drawImage。
- **测试**：`background.test.ts`（确定性、数量、坐标界内）。

### lod.ts —— 缩放分级规则表（写死、纯函数）
- **接口**：`LOD_TABLE` / `lodAt(zoom)` / `isMajorLabel(type, degree)` / `regionLabelAlpha(zoom)`。
  远景：无标签+光点+区域名；中景：全星名+光点；近景：图标+属性提示，区域名退场。航道三档常亮 0.35/0.55/0.7。
- **测试**：`lod.test.ts`（分档/单调/优先级）。

### lanes.ts / nodes.ts / labels.ts / camera.ts
- lanes：类型编码（实线=航道青、虚线=虫洞紫）、常量屏幕宽、hover/selected 只做增强；`paintEdgeGesture`（连线预览）。
- nodes：色温五类按 id 哈希确定性分派（`starTintOf`）、大小按类型分级、图标只出现在近景（LOD）、选中脉冲环。
- labels：LOD 门控 + 贪心矩形避让（`collectLabels/cullOverlapping/paintLabels`）。
- camera：`screenToWorld/worldToScreen/zoomAt（锚点不跳变，数学测试盖死）/panBy`，ZOOM [0.08,6]。
- 测试：`view-camera.test.ts`（相机 + .view）。

## 四、app 层（`src/app/`，Vue 3）

### System3D.vue —— 3D 观景模式（three.js，依赖已豁免）
- **职责**：恒星系 3D 演示（低性能配置：AA 关/无阴影/24×16 低模/MeshLambert/像素比 1.5/带与星空单 Points）。
  纹理来自 planetArt 库（`getPlanetTexture` → `THREE.CanvasTexture`），标签 DOM 投影，OrbitControls 旋转缩放，P 暂停，Esc 关闭。
- **生命周期**：只在挂载期存在（`v-if`），关闭即遍历 dispose（geometry/material/texture）+ renderer.dispose。
- **拆件注意**：`three@0.128.0` + `@types/three@0.128.0`（版本钉死——0.16x 起灯光模型变化，观感会漂）。
  大项目接入时此件与下钻视图并列，作为"观景"入口。

### 间距松弛（整形刷，收尾轮）
- `core/commands.ts` `relaxSpacingCommand(nodeIds, iterations=3)`：3 轮松弛——距离 <minDistance 的对沿连线对称推开；
  最近邻（限选中集合）>2.2×minDistance 的孤立点向最近邻挪 25%。一条原子命令，undo 逐点还原。
- UI：检查器批量卡"间距松弛"（框选后可用）。用途：笔刷/移动后把成员间距收敛回贴合带。

### makeNearestIndex（桶索引最近距离，性能件）
- `core/territory.ts`：网格桶 + 逐环外扩（best ≤ ring×cell 即停），结果与暴力法一致（`commands.test.ts` 逐点比对）。
- 用途：regions.ts 所有权场逐格点最近成员查询——C 组（300 节点）全图重算从 ~100ms 降到 ~15ms。

### store.ts —— Vue 与 core 的桥（拆件时改这里）
- **要点**：`editor` 是普通对象（命令要持有原始引用，不能被 reactive 包）；UI 靠 `ui.rev` 计数器感知变更
  （每次 exec/undo/redo 后 syncRev）。面板的 computed 里 `void ui.rev` 即可订阅。
- **动作**：`commit / runUndo / runRedo / select / setStatus / requestFit（fitRequest 通道：生成/打开后自动适配视图）/
  newDocument / loadDocumentFromText / openDocument / saveDocument`。
- **状态**：`ui.tool`（select/brush/chain/cut）、`ui.leftCollapsed/rightCollapsed`、`ui.dirty`、`ui.fitRequest`。

### host.ts —— 文件宿主适配（三档降级）
- electron（IPC 对话框）→ File System Access → 下载/上传。大项目接入时按宿主环境替换这一个文件即可。

### App.vue —— 全屏星图 + 浮层 UI + 全部画布交互
- **交互状态机**（pointerdown/move/up 按 `ui.tool` 分派）：pan（空格/中键）→ drag（单节点，renderer.dragPos 预览 +
  松手提交）→ batch-drag（多选组，直接改文档预览，松手 moveNodesCommand）→ marquee（框选，`nodesInMarquee`）→
  brush（区域笔刷：瞬时预览 + **笔画起点快照**的显式命令——工厂式捕获会被预览污染，undo 回不去，踩过的坑见
  finishBrush 注释）→ chain（逐跳提交 AddEdge，连完自动换起点）→ cut（剪线段与航道的严格相交检测，一条命令）→
  gesture（Shift+从选中节点拖出连线）。
- **键盘**：Ctrl+Z/Y/Shift+Z、Ctrl+S/O、Delete（多选优先批量）、V/B/L/C 切工具、Esc（清多选/手势）。
- **覆盖层**：hover-card（悬停小卡，`buildHoverCard`）、minimap（点击/拖动跳转，`miniJump`）。

### components/ —— 六个面板
ToolBar（工具组+文档操作+锁定）、GeneratorPanel（参数+预设 A/B/C+形态选择）、MetricsPanel（指标逐项差值）、
InspectorPanel（单件属性 + **批量操作卡**：镜像↔/↕、旋转⟳、批量删除、取消选择）、RegionsPanel（区域增删改+成员 +/−）、
LegendPanel（图例常驻）。

### electron/ —— 桌面壳（拆件时大概率整个丢弃或换壳）
`main.cjs`（窗口 + open/save 对话框 IPC）、`preload.cjs`（contextBridge 只暴露两个方法）。
不打包 exe（并入大项目），`.bat` 双击入口仅为本项目独立使用。

## 五、流程模式索引（跨文件的"招式"，拆件时按图索骥）

| 模式 | 位置 | 一句话 |
|---|---|---|
| 命令模式（撤销唯一通道） | `core/commands.ts` `exec/undo/redo` + 各 makeXxx/XxxCommand | do/undo/label；栈深 100 截断最老 |
| 批量原位插回 | `commands.ts` `deleteNodesCommand.undo` | 按**原索引升序** splice——逆序/乱序会错位（踩过的坑） |
| 瞬时预览 + 起点快照命令 | `app/App.vue` `finishBrush` | 拖拽/笔刷先直接改文档做预览，松手提交"显式 before/after"命令；工厂式捕获会被预览污染 |
| 所有权场（零重叠版图） | `core/territory.ts` φ 场 + `render/regions.ts` 等值线 | argmin 互斥 ⇒ 势力色块两两不相交；成员处 effD=0 ⇒ 色块必含成员 |
| 区域生长（加权归属） | `core/territory.ts` `growRegions` | Prim 式 claim（cost=dist/weight），根贪心 max-min 限内圈 |
| 航道稀疏化管线 | `core/topology.ts` `buildLanes` | 候选→贪心+度上限→不交叉成环→最短桥接 |

## 七、大项目接入清单（最短路径）

1. 拷 `src/core/` 整目录 + `tests/`（core 相关）——零依赖，直接可用；
2. 渲染要"贴边版图"：拷 `territory.ts + geometry.ts + regions.ts`，输入只需成员坐标分组 + minDistance + seed；
3. 存取接缝：`serializer.ts` 的 `GalaxyDoc` JSON；或直接复用 `commands.ts` 的 EditorState（撤销白拿）；
4. 替换 `app/host.ts` 为大项目的存储服务（实现 openFile/saveFile 两个方法）；
5. 数据契约加字段：可选 + 缺省不写出 + parse 枚举校验（照 `shape` 的先例）；
6. 拆走任何件前跑对应测试；动 generator 前 `$ npx vitest run tests/faction-layout.test.ts tests/territory.test.ts`。

——完。拆件有问题先看本文档第二节与第五节，再读对应测试文件（测试即规格）。
