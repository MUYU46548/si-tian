## 红线

1. **Vue 3 响应式**：修改 ref 嵌套属性必须创建新对象
2. **Undo 铁律**：所有数据修改走 execute 栈
3. **性能**：禁止在 render/Math.random()
4. **测试**：每批次完成后跑 `npm run test` 确认 20/20 全绿
5. **构建**：`npm run build` 无 >500 kB 警告
6. **Mock 红线**：`dist/index.html` 不得含 `__SITIAN_MOCK__`
7. **Icon 组件优先**：优先使用 `Icon.vue` 已有的 107 个图标，确实没有的才新增
8. **测试选择器**：替换 emoji 时，同步将依赖 emoji 文本的测试选择器改为 `data-testid` 或 `title` 属性
