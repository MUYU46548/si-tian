# 司天 · 历史剧本操作手册

> 面向「想画一张能拿出去用的历史版图」的人。
> 全文只讲**怎么做**与**为什么这么做**；数据落在哪见 §7。

---

## 0. 先破除一个误解：司天的「省份」和 EU4 的不是一回事

这是最容易卡住的地方，务必先读。

| | EU4 | 司天 |
|---|---|---|
| 省份从哪来 | 地图文件里**预生成**的 4000+ 个固定格 | **你自己画的多边形**（也可从 `.map` 导入） |
| 你平时改什么 | 只改 owner（这块地归谁） | ① 边界形状 ② 归属 |
| 画边界的工具 | ——（不存在，从不画） | **自由绘制 (B)** |
| 改归属的工具 | 点省份改 owner | **变更归属 (Q)** / **点击填充 (O)** |

**结论**：在司天里说「我要手绘省界」，你要找的工具叫 **自由绘制 (B)**，不叫「归属笔刷」。
归属笔刷只改「这块地归谁」，**不动边界一根线** —— 拿它画边界自然觉得"给错了东西"。

司天还有一层 EU4 没有的区分，别混：

- **底图编辑** = 世界的物理底子（高度 / 群系 / 河流 / 海岸 / 省界几何）
- **剧本模式** = 政治史（势力 / 归属 / 易主 / 逐年切片）

工具栏右上角「模式」下拉在这里切。

---

## 1. 三十秒心智模型

```
底图（世界地形 + 省界骨架）
   └── 剧本（一个时间点）  =  谁占了哪些省
          ├── 势力列表（颜色 + 名称）
          └── 归属：省 → 势力（可带易主日期）
```

- **一个剧本 = 一个时间点的版图快照**。EU4 那张「选择历史时期」列表，在这里就是左侧的「历史剧本」栏。
- 省是**跨剧本共享**的（同一块地，在不同剧本里可以属于不同势力）；势力是**剧本内**的。

## 2. 完整流程（从空项目到出图）

### 阶段 1 · 准备底图

进入「历史剧本」后，看工具栏「底图：」下拉：

- **已有底图**：直接选一张。括号里写着它有几个省。
- **导入**：点旁边的 `+`，选 Azgaar / FMG 导出的 `.map` 文件 —— **这是最省事的路径**，它会连省份边界和势力一起带进来。
- **从零开始**：点「图层」图标（`basemap-create-heightmap`）给这张底图建一个高度图网格，之后才能用高度 / 群系 / 河流笔刷。

> 「地形：跟随 / 冻结」是什么意思？
> **冻结导入** = 把某颗行星的地形复制一份到这张底图（副本独立，之后互不影响）→ 适合**历史存档剧本**。
> **跟随** = 和行星共用同一份数据（在剧本里涂山会改到行星）→ 适合**当代同步构建的地图**。
> 历史剧本一律选**冻结**。

### 阶段 2 · 划分省份

这是你认为「找不到」的那一步。

1. 工具栏点 **画省份**（旧名「自由绘制」，按 `B`）
2. **按住鼠标沿轮廓拖一圈** → 抬手即生成一个省
3. 建完会自动选中，右侧属性面板出现，可以直接改名
4. 形状不满意 → **改形状**（旧名「顶点编辑」，`G`）拖顶点；右键顶点删除；点击边插入
5. 一个省想拆成两个 → **拆分 (X)**，点两个点定义分割线
6. 两个省想并成一个 → **合并 (M)**，依次点两个省
7. 删除 → **删除 (E)** 点一下

> 💡 拖动地图查看 = **选择 (V)** + 拖动，或按住**空格**再拖。
> 默认工具就是「选择」，所以拖地图不会误建省。
> 画笔模式下也能缩放：**Ctrl + 滚轮**。

**海域**是特殊省份：用属性面板把「类型」改成 `sea`。海域**不参与势力归属**，也不进时间轴。

### 阶段 3 · 建立势力

切到 **剧本模式** → 顶部出现「势力」色板：

- 点 **`+ 势力`** 新建一个，可改名称 / 简称 / 配色
- 简称只在缩小档显示，留空就用全名

> 如果色板是空的且「`+ 势力`」不可点 → 是只读态（没打开项目）。先到「项目」面板新建或打开一个 `.sitian` 项目。

### 阶段 4 · 划定归属与易主

选中一个势力（色板里点亮它），然后：

| 工具 | 快捷键 | 用法 |
|---|---|---|
| 变更归属 | `Q` | **按住涂抹**，笔刷划过的格子归给所选势力，省界自动重算 |
| 自由轮廓 | `L` | 按住画一圈，**圈内所有格**整批划归（不用描点） |
| 点击填充 | `O` | 点一下，所在**封闭区域整块**划归（超过全图 25% 会拒绝，防止一下填满大陆） |
| 势力油漆桶 | `P` | 在「更多」里，点省份指派势力 |

批量：**Ctrl / ⌘ + 点击**多选省份 → 底部出现批量条 → 一次指派 / 一次清除（算一条撤销）。

**易主日期**怎么录？左边「历史剧本」栏选到目标时期 → 把游标拖到那一年 → 再涂。涂的当下就是「这一年这块地易主了」。

### 阶段 5 · 出图

工具栏第 5 行（点「更多」展开）：

- **导出 PNG** —— 当前剧本 / 年份的位图
- **导出 SVG** —— 矢量图，可进 Illustrator / Inkscape 继续加工
- **逐年切片导出** —— 每个状态变化的年份一张图 + 一份 `frames.json` 清单，可交 ffmpeg 合成动画
- **导出 / 导入 JSON** —— `scenarios.json`，用于跨项目搬运

## 3. 左侧「历史剧本」栏怎么用

这是**选择时期**的地方（对应 EU4 那张「选择历史时期」列表）：

- 每条显示：罗马数字 + 剧本名 + 起止年 + `势力数 · 已归属省数`
- **点一条 = 切到那个时期**：编辑目标、地图着色、时间轴游标**一起**跟着变
- 点标题栏右侧的箭头可以收起，腾出画布空间
- 底部 **「新建 / 管理剧本…」** 打开剧本管理：新建、编辑、删除，以及管理当前剧本的地名与标记

**「上一剧本 / 下一剧本」和这个列表不是一回事**：

- 列表 = **选择**（跳到某个时期）
- 上一 / 下一剧本 = **按顺序推进**（翻页，用于顺着看演变）

两个都留着，按需要选。

时间轴上还能：**播放演变**（约 1.3s 一个剧本）、**按年比例 / 等宽**切换轴向、**斜线占领 / 白描边**切换变化图层、**存为切片点**（给某个具体日期打书签）。

## 4. 常见误区（踩过的坑）

| 现象 | 真相 |
|---|---|
| 「我拖地图，结果在建省」 | 默认工具曾是「自由绘制」。**现已改为「选择」**；画省请显式按 `B`。 |
| 「归属笔刷涂出来的边界很丑 / 海岸线变得不对劲」 | 归属笔刷**会重算省界**，而省界同时承担"陆海轮廓"的显示 → 涂得多了海岸线就变了形（变成格点提取 + 平滑后的规则波浪线）。**海岸线不该用笔刷画** —— 它来自底图（导入的地形 / 高度图）。要手改行政边界请用 **画省份 (B)** / **改形状 (G)**。 |
| 「笔刷最小了还是很大」 | 归属笔刷的最小半径 = **1 个网格格**，而网格格宽 = 高度图格宽（可能很大）→ 这是**网格粒度**决定的，滑块已经到最小，不是设置问题。 |
| 「涂坏了想回到之前」 | ① `Ctrl+Z` 逐条撤（栈上限 **100 条**）；② 工具栏「更多」→ **撤销历史面板**（列出全部操作，**点任意一步直接跳过去**）；③ 项目面板 → **快照回滚**（更早的状态）。 |
| 「切了模式，画布没反应，得点一下才更新」 | 已修（`onModeChange` 补了重绘）。 |
| 「保存失败」但没说原因 | 把鼠标**停在**状态栏的「保存失败」上，悬停提示里就是具体原因。它不会自动消失，要等下一次成功保存才清。 |
| 「省份列表是空的，画笔点了没反应」 | 底图还没有高度图网格。用「底图」旁的图层按钮建一个。 |
| 「几个"省份"面板，搞不清哪个是哪个」 | 底图编辑里的地形块（森林 / 海洋…）和剧本里的行政区是**两套东西**。政治划分看**剧本模式**。 |

## 5. 快捷键

**文件 / 全局**

| 键 | 作用 |
|---|---|
| `Ctrl + Q` | 退出司天（**会弹确认框**，不会误触即退） |
| `Ctrl + Z` / `Ctrl + Y` | 撤销 / 重做 |
| `F1` | 关于 |
| `Esc` | 取消当前操作 / 关闭面板 |

**画布**

| 键 | 作用 |
|---|---|
| `V` | 选择（拖动平移） |
| `B` | 自由绘制（建省） |
| `Q` | 变更归属 |
| `G` | 顶点编辑 |
| `X` / `M` / `E` | 拆分 / 合并 / 删除省 |
| `L` / `O` | 自由轮廓 / 点击填充 |
| `H` / `N` / `W` / `I` | 高度 / 群系 / 河流 / Relief 图标 |
| `P` | 势力油漆桶 |
| `C` / `R` / `U` | 文化 / 宗教 / 智能聚落 |
| `T` / `K` / `J` | 地名 / 标记 / 道路 |
| `F` | 适应画布 |
| **空格 + 拖动** | 平移（任何工具下都可用） |
| **滚轮** | 画笔模式下调半径；**Ctrl + 滚轮** = 缩放 |
| `Shift`（绘制时） | 临时关闭吸附 |

## 6. 数据落在哪

- 项目文件：`<你选的位置>/xxx.sitian`（单个 JSON，含实体树 + 剧本 + 地图 + 快照）
- 自动备份：同级 `backups/`
- 撤销栈：满 50 条，**快照不含地形高度图**（省空间，见界面说明）
- 退出时：主进程会**先尝试落盘未保存的改动**；只有落盘失败才会弹原生对话框问你要不要放弃

> 「从 Obsidian 重新提取」在打开项目后不可用（会被事实源冲突拦下）——
> 要把知识库内容带进项目，用项目面板的**「导入知识库内容」**（只补缺，一条撤销）。
