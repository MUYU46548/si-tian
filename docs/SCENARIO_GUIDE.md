# 司天 · 历史剧本操作手册

> 面向「想画一张能拿出去用的历史版图」的人。
> 全文只讲**怎么做**与**为什么这么做**；数据落在哪见 §7。

---

## 0. 先破除一个误解：司天的「省份」和 EU4 的不是一回事

这是最容易卡住的地方，务必先读。

| | EU4 | 司天 |
|---|---|---|
| 省份从哪来 | 地图文件里**预生成**的 4000+ 个固定格 | **你自己画的多边形**（也可从 `.map` 导入） |
| 你平时改什么 | 只改 owner（这块地归谁） | ① 边界形状 ② 归属 |
| 画边界的工具 | ——（不存在，从不画） | **自由绘制 (B)** |
| 改归属的工具 | 点省份改 owner | **变更归属 (Q)** / **点击填充 (O)** |

**结论**：在司天里说「我要手绘省界」，你要找的工具叫 **自由绘制 (B)**，不叫「归属笔刷」。
归属笔刷只改「这块地归谁」，**不动边界一根线** —— 拿它画边界自然觉得"给错了东西"。

司天还有一层 EU4 没有的区分，别混：

- **底图编辑** = 世界的物理底子（高度 / 群系 / 河流 / 海岸 / 省界几何）
- **剧本模式** = 政治史（势力 / 归属 / 易主 / 逐年切片）

工具栏右上角「模式」下拉在这里切。

## 1. 三十秒心智模型

```
底图（世界地形 + 省界骨架）
   └── 剧本（一个时间点）  =  谁占了哪些省
          ├── 势力列表（颜色 + 名称）
          └── 归属：省 → 势力（可带易主日期）
```

- **一个剧本 = 一个时间点的版图快照**。EU4 那张「选择历史时期」列表，在这里就是左侧的「历史剧本」栏。
- 省是**跨剧本共享**的（同一块地，在不同剧本里可以属于不同势力）；势力是**剧本内**的。

## 2. 完整流程（从空项目到出图）

### 阶段 1 · 准备底图

进入「历史剧本」后，看工具栏「底图：」下拉：

- **已有底图**：直接选一张。括号里写着它有几个省。
- **导入**：点旁边的 `+`，选 Azgaar / FMG 导出的 `.map` 文件 —— **这是最省事的路径**，它会连省份边界和势力一起带进来。
- **从零开始**：点「图层」图标（`basemap-create-heightmap`）给这张底图建一个高度图网格，之后才能用高度 / 群系 / 河流笔刷。

> 「地形：跟随 / 冻结」是什么意思？
> **冻结导入** = 把某颗行星的地形复制一份到这张底图（副本独立，之后互不影响）→ 适合**历史存档剧本**。
> **跟随** = 和行星共用同一份数据（在剧本里涂山会改到行星）→ 适合**当代同步构建的地图**。
> 历史剧本一律选**冻结**。

### 阶段 2 · 划分省份

这是你认为「找不到」的那一步。

**先决定走哪条路** —— 司天的省份是你自己画的多边形，所以有两条：

| 你要什么 | 用哪个 | 一次得到几块 |
|---|---|---|
| **一张图上切四五百块**（EU4 那种密度） | **批量铺底 (A)** | 一次 **N 块**（N 随便填，400 / 500 都行） |
| 精修某几块、让它长得像历史边界 | **折线切割 (D)** | 一次 2 块（可沿山脊、海岸、河流任意弯） |
| 从零画一块大陆的轮廓（要精确边界） | **画省份 (B)** | 一次 1 块 |
| **像画图一样涂出一块地**（空底图第一笔最快） | **笔刷建省 (Shift+B)** | 一次 1 块（不用闭合） |

> 🖌 **笔刷建省 (Shift+B)**（2026-10-22 加，在「底图编辑」行、也在日常模式的省份行）：
> 按住左键像涂色一样抹，**松手抹过的范围就是一个省** —— 不用闭合、不会画出自交怪形，
> 涂抹过程中的黄色笔迹带就是最终形状。它**只长在空地上**：已有省份覆盖的地方涂不上
> （这样省份不会互相压叠）；要改已有省份的形状用 **改省界 (Shift+Q)**，要改归属用 **涂归属 (Q)**。
> 一笔 = 一条撤销。半径用工具行的「半径」滑杆（屏幕像素，缩放时手感一致）。

#### 推荐组合：**铺底 + 精修**

1. **批量铺底 (A)**：
   - 先在**画布上圈定范围**：默认是「全部陆地」（这张底图所有陆地省合起来的地盘）；
     也可以用**选择 (V) + Ctrl 点击**选中几个省 → 范围改成「选中的省份」，只重切那几块。
   - 填**块数**（想要四百多块就填 450），**抖动**决定形状自然度（0 = 棋盘格，0.6 左右最像手绘政区）。
   - 点 **自动播种** → 画布上出现种子点和淡色分界线预览；不满意就 **换一批**（每次形状都不一样）。
   - **也可以在画布上手动点**放种子点（右键 / Alt+点击去掉最近的），想密的地方多点几下。
   - 点 **一键切分** → 等几秒到几十秒（真实底图 2.5 万点边界切 500 块约 20 秒，进度写在工具栏上）。
   - 结果：**一次得到 N 块**，彼此共边无缝、**海岸线一个点都不动**、**归属与易主记录自动继承给新块**，
     而且**一整批只算一条撤销**（`Ctrl+Z` 整批撤回）。
2. **折线切割 (D)** 精修：
   - 在要改的那块上**逐点点击**画一条折线（想怎么弯就怎么弯）→ **双击**或按 `Enter` 切开。
   - 两端落在省外也没关系（会自动沿切向延长）；`Backspace` 退一个点，`Esc` 取消。
   - 画布上会实时显示两半：**绿色那半保留原省份的身份**（名字 / 归属 / 时间轴都跟着它），
     橙色那半是新省 —— 想换边就按住 `Shift` 再点一下。

其余单块操作：

3. 建完会自动选中，右侧属性面板出现，可以直接改名
4. 形状不满意 → **改形状**（旧名「顶点编辑」，`G`）拖顶点；右键顶点删除；点击边插入
5. 一个省想拆成两个 → **拆分 (X)**，点两个点定义**直线**切割线（要折线用上面的 `D`）
6. 两个省想并成一个 → **合并 (M)**，依次点两个省
7. 删除 → **删除 (E)** 点一下

> 💡 拖动地图查看 = **选择 (V)** + 拖动，或按住**空格**再拖。
> 默认工具就是「选择」，所以拖地图不会误建省。
> 画笔模式下也能缩放：**Ctrl + 滚轮**。

**海域**是特殊省份：用属性面板把「类型」改成 `sea`。海域**不参与势力归属**，也不进时间轴。

### 阶段 3 · 建立势力

切到 **剧本模式** → 顶部出现「势力」色板：

- 点 **`+ 势力`** 新建一个，可改名称 / 简称 / 配色
- 简称只在缩小档显示，留空就用全名

> 如果色板是空的且「`+ 势力`」不可点 → 是只读态（没打开项目）。先到「项目」面板新建或打开一个 `.sitian` 项目。

### 阶段 4 · 划定归属与易主

选中一个势力（色板里点亮它），然后：

| 工具 | 快捷键 | 用法 |
|---|---|---|
| 变更归属 | `Q` | **按住涂抹**，笔迹划过的地盘归给所选势力（目标省并入、相交省挖去，**精确多边形布尔**） |
| 自由轮廓 | `L` | 按住画一圈，**圈内的地**整批划归（不用描点） |
| 点击填充 | `O` | 点一下，**把点击处那一整块省**吞并给所选势力 |
| 势力油漆桶 | `P` | 在「更多」里，点省份指派势力 |

> 🔒 **锁定海岸线**（默认开，工具栏「涂归属」旁）：涂归属 / 圈选只在**已有省份范围内**易手，
> **永远不会把海岸线涂出去**。要改海岸线请去**底图编辑**。取消勾选才允许往海面扩张。
> 笔刷半径是**世界单位**，最小 1 —— 可以贴着海岸线描。

批量：**Ctrl / ⌘ + 点击**多选省份 → 底部出现批量条 → 一次指派 / 一次清除（算一条撤销）。

**易主日期**怎么录？左边「历史剧本」栏选到目标时期 → 把游标拖到那一年 → 再涂。涂的当下就是「这一年这块地易主了」。

### 阶段 5 · 出图

工具栏第 5 行（点「更多」展开）：

- **导出 PNG** —— 当前剧本 / 年份的位图
- **导出 SVG** —— 矢量图，可进 Illustrator / Inkscape 继续加工
- **逐年切片导出** —— 每个状态变化的年份一张图 + 一份 `frames.json` 清单，可交 ffmpeg 合成动画
- **导出 / 导入 JSON** —— `scenarios.json`，用于跨项目搬运

## 3. 左侧「历史剧本」栏怎么用

这是**选择时期**的地方（对应 EU4 那张「选择历史时期」列表）：

- 每条显示：罗马数字 + 剧本名 + 起止年 + `势力数 · 已归属省数`
- **点一条 = 切到那个时期**：编辑目标、地图着色、时间轴游标**一起**跟着变
- 点标题栏右侧的箭头可以收起，腾出画布空间
- 底部 **「新建 / 管理剧本…」** 打开剧本管理：新建、编辑、删除，以及管理当前剧本的地名与标记

**「上一剧本 / 下一剧本」和这个列表不是一回事**：

- 列表 = **选择**（跳到某个时期）
- 上一 / 下一剧本 = **按顺序推进**（翻页，用于顺着看演变）

两个都留着，按需要选。

时间轴上还能：**播放演变**（约 1.3s 一个剧本）、**按年比例 / 等宽**切换轴向、**斜线占领 / 白描边**切换变化图层、**存为切片点**（给某个具体日期打书签）。

## 4. 常见误区（踩过的坑）

| 现象 | 真相 |
|---|---|
| 「我拖地图，结果在建省」 | 默认工具曾是「自由绘制」。**现已改为「选择」**；画省请显式按 `B`。 |
| 「我想切四五百块，难道要点 400 次？」 | **不用。** 用 **批量铺底 (A)**：播 N 个点 → 一键切出 N 块。逐个手切那条路（拆分 `X`）是给**精修**用的。 |
| 「归属笔刷涂出来的边界很丑 / 海岸线变得不对劲」 | 已修（2026-10-09 起改为**矢量布尔**：涂抹只改边界多边形，精度不再降级；`fromGrid` 那条"格点轮廓反写多边形"的路已删除）。再加一道 **锁定海岸线**（默认开）：涂不到海里去。 |
| 「笔刷最小了还是很大」 | 半径是**世界单位**，最小 **1**（2026-10-09 起，原为 10）。 |
| 「涂坏了想回到之前」 | ① `Ctrl+Z` 逐条撤（栈上限 **100 条**）；② 工具栏「更多」→ **撤销历史面板**（列出全部操作，**点任意一步直接跳过去**）；③ 项目面板 → **快照回滚**（更早的状态）。批量铺底算**一条**，一次 `Ctrl+Z` 整批回。 |
| 「切了模式，画布没反应，得点一下才更新」 | 已修（`onModeChange` 补了重绘）。 |
| 「保存失败」但没说原因 | 状态栏的「保存失败」后面**直接写着原因**（截断 60 字，悬停看全文）。它不会自动消失，要等下一次成功保存才清。 |
| 「省份列表是空的，画笔点了没反应」 | 这张底图上还没有省份。点 **画省份 (B)** 拖一圈建第一块，或 **批量铺底 (A)** 直接铺一片。 |
| 「几个"省份"面板，搞不清哪个是哪个」 | 底图编辑里的地形块（森林 / 海洋…）和剧本里的行政区是**两套东西**。政治划分看**剧本模式**。 |

## 5. 快捷键

**文件 / 全局**

| 键 | 作用 |
|---|---|
| `Ctrl + Q` | 退出司天（**会弹确认框**，不会误触即退） |
| `Ctrl + Z` / `Ctrl + Y` | 撤销 / 重做 |
| `F1` | 关于 |
| `Esc` | 取消当前操作 / 关闭面板 |

**画布**

| 键 | 作用 |
|---|---|
| `V` | 选择（拖动平移） |
| `B` | 自由绘制（建省） |
| `D` | **折线切割**（沿任意折线把省切成两块） |
| `A` | **批量铺底**（Voronoi 一次切出 N 块） |
| `Q` | 变更归属 |
| `G` | 顶点编辑 |
| `X` / `M` / `E` | 拆分（直线）/ 合并 / 删除省 |
| `L` / `O` | 自由轮廓 / 点击填充 |
| `H` / `N` / `W` / `I` | 高度 / 群系 / 河流 / Relief 图标 |
| `P` | 势力油漆桶 |
| `C` / `R` / `U` | 文化 / 宗教 / 智能聚落 |
| `T` / `K` / `J` | 地名 / 标记 / 道路 |
| `F` | 适应画布 |
| **Enter / 双击** | 折线切割 / 自由绘制：收口成型 |
| **Backspace**（折线切割中） | 退掉最后一个点 |
| **Shift**（折线切割中） | 换哪一半保留原省份身份 |
| **空格 + 拖动** | 平移（任何工具下都可用） |
| **滚轮** | 画笔模式下调半径；**Ctrl + 滚轮** = 缩放 |
| `Shift`（绘制时） | 临时关闭吸附 |

## 6. 数据落在哪

- 项目文件：`<你选的位置>/xxx.sitian`（单个 JSON，含实体树 + 剧本 + 地图 + 快照）
- 自动备份：同级 `backups/`
- 撤销栈：满 100 条（`store/undo.js` 的 `MAX_HISTORY`），**快照不含地形高度图**（省空间，见界面说明）
- 退出时：主进程会**先尝试落盘未保存的改动**；只有落盘失败才会弹原生对话框问你要不要放弃

> 「从 Obsidian 重新提取」在打开项目后不可用（会被事实源冲突拦下）——
> 要把知识库内容带进项目，用项目面板的**「导入知识库内容」**（只补缺，一条撤销）。
