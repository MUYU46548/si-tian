# SiTian 笔记编写规范

> **目标**：让用户以最小的额外负担，写出能被 SiTian 正确提取的 Obsidian 笔记。

---

## 核心原则

1. **零侵入**：不改变用户的写作习惯，笔记依然可以在 Obsidian 中正常使用
2. **渐进增强**：不填任何额外字段也能工作，填写后地图更精确
3. **可选覆盖**：所有字段都是可选的，SiTian 会自动推断

---

## 快速开始

### 最小可用写法

只需要一个 frontmatter 字段：

```yaml
---
层级: 城市
---
```

SiTian 会自动：
- 从文件名提取节点名称
- 从文件夹结构推断父节点
- 从笔记内容推断 biome（生物群系）

### 推荐写法

```yaml
---
层级: 城市
上层区域: [[霜寒主星]]
标签:
  - 城市
  - 首都
  - biome/tundra
---

# 霜寒城

北方冰原上的永久定居点，常年积雪...
```

## 字段参考

### 必须字段（让 SiTian 识别节点类型）

| 字段 | 说明 | 示例 |
|:---|:---|:---|
| `层级` | 节点类型（中文） | `世界`、`星域`、`星系`、`行星`、`城市`、`城镇`、`村庄`、`地点` |

**注意**：`层级` 也可以通过文件夹结构自动推断。比如笔记放在 `11 地理系统/星系/` 文件夹下，层级自动为 `星系`。

### 推荐字段（让地图更精确）

| 字段 | 说明 | 示例 |
|:---|:---|:---|
| `上层区域` | 父节点名称（wikilink 格式） | `[[霜寒主星]]`、`[[北境星域]]` |
| `标签` | 节点标签（用于自动推断 biome） | `biome/tundra`、`biome/forest` |

### 可选字段（高级用户）

| 字段 | 说明 | 示例 |
|:---|:---|:---|
| `地点类型` | 地点分类 | `自然`、`宗教`、`皇室`、`商业`、`工业`、`居住`、`公共`、`特殊` |

## 层级与文件夹对应关系

| 层级 | 中文 | 默认文件夹路径 |
|:---|:---|:---|
| `world` | 世界 | `11 地理系统/` 下的世界索引 |
| `star_domain` | 星域 | `11 地理系统/星域/` |
| `galaxy` | 星系 | `11 地理系统/星系/` |
| `planet` | 行星 | `11 地理系统/行星/` |
| `city` | 城市 | `02 场景地点/` |
| `town` | 城镇 | `02 场景地点/` |
| `village` | 村庄 | `02 场景地点/` |
| `location` | 地点 | `02 场景地点/` |

**提示**：如果笔记放在正确的文件夹中，`层级` 字段可以省略。

## Biome 自动推断

SiTian 会从笔记标题、正文、标签中自动推断生物群系（biome），用于地图着色。

### 推断规则（按优先级）

1. **标签精确匹配**：`#biome/tundra` → 冻原
2. **标题关键词**：标题包含"雪"、"冰"、"寒" → 冻原
3. **正文关键词**：正文包含"雨林"、"热带" → 热带雨林

### 支持的 Biome 类型

| Biome | 标签 | 关键词 |
|:---|:---|:---|
| 冻原 | `biome/tundra` | 雪、冰、冻、寒、极、霜 |
| 沙漠 | `biome/desert` | 沙、漠、旱、燥、荒 |
| 热带雨林 | `biome/rainforest` | 雨林、热带、潮湿、茂密 |
| 森林 | `biome/forest` | 林、树、木、森、松、柏 |
| 草原 | `biome/grassland` | 草原、草地、牧场、丘陵 |
| 湿地 | `biome/wetland` | 湿地、沼泽、湖泊、河流 |
| 山地 | `biome/mountain` | 山、峰、岭、崖、峡谷 |
| 海洋 | `biome/ocean` | 海、洋、深海、海岸 |
| 城市 | `biome/urban` | 城、镇、村、聚落 |

## 常见问题

### Q: 不填任何字段，SiTian 能识别吗？

**能**。SiTian 会：
- 从文件名提取节点名称
- 从文件夹结构推断层级
- 从笔记内容推断 biome

但显式填写 `层级` 和 `上层区域` 会更准确。

### Q: 上层区域怎么填？

使用 Obsidian 的 wikilink 格式：`[[节点名称]]`。

```yaml
上层区域: [[霜寒主星]]
```

### Q: 标签有什么用？

1. **自动推断 biome**：`#biome/tundra` → 冻原色
2. **区域提取**：共享相同标签的地点会被自动归为一个区域
3. **搜索过滤**：在 SiTian 中按标签筛选节点

### Q: 坐标怎么设置？

**不需要手动设置**。SiTian 会自动布局，用户可以在地图上拖拽调整。

如果一定要手动设置（比如从旧数据迁移），可以在 frontmatter 中添加：

```yaml
coordinate:
  x: 700
  y: 500
```

### Q: 重命名笔记后，地图上的节点会丢失吗？

**不会**。SiTian 使用 UUID 作为节点的稳定标识，重命名后 UUID 不变，地图关联保留。

## 迁移指南

### 从旧版本 SiTian 迁移

如果你之前使用过 SiTian，笔记中可能有 `coordinate` 字段。这些字段会被保留，无需修改。

### 从其他工具迁移

如果你有现成的世界观数据（JSON、CSV 等），可以：
1. 写一个转换脚本，输出为 Obsidian Markdown 格式
2. 放在对应的文件夹中
3. 运行 `npm run extract-data` 提取

## 总结

| 操作 | 工作量 | 效果 |
|:---|:---|:---|
| 什么都不做 | 零 | 自动推断，基本可用 |
| 加 `层级` 字段 | 低 | 精确识别节点类型 |
| 加 `上层区域` | 低 | 精确层级关系 |
| 加 `biome/xxx` 标签 | 低 | 地图自动着色 |
| 手动设置坐标 | 中 | 精确控制位置 |

**建议**：先让 SiTian 自动推断，不满意再逐步添加字段。
