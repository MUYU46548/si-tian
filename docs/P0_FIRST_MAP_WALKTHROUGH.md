## 三步（照做即可，约 3 分钟）

**第 0 步 · 打开项目**
司天 → 项目面板 → 打开 `绒花计划`。打开后状态栏应能看到 `415 省份`。

**第 1 步 · 画一个势力范围**
1. 世界选择页点 **「历史剧本」** 进入剧本视图。
2. 左栏点一条剧本（推荐 **诸侯割据**：7 个势力、颜色分得开）。
3. 工具栏点 **「改归属」**（油漆桶，快捷键 `Q`）。
4. 在右侧色板点一个势力（例如「玄方」）。
5. 在画布上**按住拖动**扫过几块省份，或**单点**一块省 → 状态栏出现
   `「<省名>」→ 玄方（易主日期 <年>）`。
   → 这一步就是"画一个势力范围"；**松手即落库**（自动保存约 800ms）。
   ⚠️ 若点到城镇图标而不是省份：先把「城镇」图层关掉（改归属优先命中城镇是既有设计）。

**第 2 步 · 选一个时间点**
1. 工具栏正下方的时间轴：**拖动游标**或用「上一剧本 / 下一剧本」。
2. 状态栏/画布右下会显示当前年份与该剧本的易主进度（形如 `本剧本 183 省易主 · 截至本日已落定 92`；后者是游标日期前已经发生的条数）。
3. 无需手工录日期：**没录过的易主日期会按剧本区间均匀铺开**（合成值），所以**换年份图真的会变**。

**第 3 步 · 导出一张 PNG**
1. 工具栏点 **「更多」** 展开（导出按钮在「更多」里，默认收起）。
2. 点 **「导出 PNG」**（图片图标，`data-testid=export-png`）→ 系统保存对话框 → 存盘。
3. 状态栏出现 `已导出 PNG：<路径>`。

## 导出能力（如实说，别期望过高）

| 项 | 现状 |
|---|---|
| 范围 | **整张图**（全部省份的包围盒 + 40 世界单位留白）—— **不是**当前视野 |
| 分辨率 | **固定 2 倍**（SVG 尺寸 ×2），**没有倍率选项** |
| 内容 | 省份填色 / 势力色 / EU4 斜线（该模式下）/ 省名标注 / 势力图例（含各省计数）/ 剧本名 + 年份标题 |
| 想要别的范围 / 更高倍率 | 先用「导出 SVG」或「逐年切片导出」出矢量图，再在外部工具里裁 / 放大 |
| 真实数据实测 | `desite` + 诸侯割据 + 510 年 → **3680×1752 px / 3.38 MB**，7 个势力色全部有像素，文字像素（有标注减无标注）446489 px |
