## 四、中长期开发计划

### 设计原则（沿用 06 号，只改一条）

1. **阶段门制**：一个阶段 = 一个施工单位 = 一次交付。不设中间检查点，你只在阶段门出场。
2. **每个阶段门必须打包并 push**（针对 A1/A2）。本轮全局门 = 接口化完成后的 0.5.0；
   **打包 + push 是阶段门的最后两个判据**，不是可选项。
3. **判据先立**：进入阶段前写死"怎么算完成"，完成即销账，不留"基本可用"。
4. **不接"前置未到"的活**：A4 那类"等接口化再做"的项，要么真等，要么改文档，不许挂着。
5. **止损点先立**：任何"攒着一起交"的阶段都必须写上最长时限与超期降级方案。
6. 量级用"周"，是量级不是承诺。

### N1 · 渲染层接口化（2–3 周，1 个阶段门）

**目标**：把 `ScenarioMap` 的 28 个 `draw*` 收成一张注册表，先只接剧本视图。

- 接口形状（`NEXT_STAGE` 已定，不重新发明）：`{ id, order, when(state), draw(ctx, view), cacheable, quality }`
- **分两刀，每刀一次全量回归**：
  - 刀 1：底图 / 海岸浅滩 / 省界 / 文字标注四层（画得最重、耦合最低）
  - 刀 2：笔刷覆盖 / 预览层 / 选中态 / 小地图
- **不做**：不碰行星/区域/建筑三视图（它们各有各的问题，另议）。

**判据（写死）**：
1. 重构前后**同机位截图逐像素一致**（允许抗锯齿差异）
2. p95 帧时不退化（用 `CHASSIS_BASELINE` 同一套探针、同一台机器）
3. 163 CDP + 72 单测全绿
4. `ScenarioMap.vue` 行数**下降 ≥40%**（14,206 → ≤8,500）

**完成后立刻解锁**：美术质感层（手绘风/写实风/多投影）从"排队"变成"可施工"。这一条要在阶段门写进文档。

**两条硬约束（防止这面墙变成第二个悬空承诺）**：
1. **刀 1 完必须出一次内测包**给你过一眼（不是发版，5 分钟）：四层迁完若观感有任何变化，此时发现最便宜。
2. **上限 3 周**。超期未达判据 → **停止重构、按当前状态打包发 0.5.0**，接口化降级为下一阶段续做。

### N3 · 能力补齐（2–3 周，按你选的优先级排）

候选池（你挑 2–3 项进本阶段，其余顺延）：

- **外交表 UI**：数据层已有（事件账本），只差视图。成本最低、见效最快。
- **读料桥补全**：提取 → **稳定 ID 绑定**（改名/重画不丢名字）+ 候选导入。这是"点图看设定"真正可用的最后一步。
