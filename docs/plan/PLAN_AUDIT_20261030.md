## 四、中长期开发计划

### 设计原则（沿用 06 号，只改一条）

1. **阶段门制**：一个阶段 = 一个施工单位 = 一次交付。不设中间检查点，你只在阶段门出场。
2. **每个阶段门必须打包并 push**（针对 A1/A2）。本轮全局门 = 接口化完成后的 0.5.0；
   **打包 + push 是阶段门的最后两个判据**，不是可选项。
3. **判据先立**：进入阶段前写死"怎么算完成"，完成即销账，不留"基本可用"。
4. **不接"前置未到"的活**：A4 那类"等接口化再做"的项，要么真等，要么改文档，不许挂着。
5. **止损点先立**：任何"攒着一起交"的阶段都必须写上最长时限与超期降级方案。
6. 量级用"周"，是量级不是承诺。

> p95 三档一致（25.0→25.3 属噪声）→ **判据 2 通过**。`max` 的单帧 51ms 出现在拖动起步首帧
> （提取前同一位置也出现过 45.8 / 34.1），后续每一刀继续用同一 A/B 法复核。

**完成后立刻解锁**：美术质感层（手绘风/写实风/多投影）从"排队"变成"可施工"。这一条要在阶段门写进文档。

**两条硬约束（防止这面墙变成第二个悬空承诺）**：
1. **刀 1 完必须出一次内测包**给你过一眼（不是发版，5 分钟）：四层迁完若观感有任何变化，此时发现最便宜。
2. **上限 3 周**。超期未达判据 → **停止重构、按当前状态打包发 0.5.0**，接口化降级为下一阶段续做。
   理由：你选了"做完一起发"，就必须有一个止损点，否则交付断档会从 4 天变成 1 个月。

### N3 · 能力补齐（**四项全做**，2026-10-30 拍板；拆成两个阶段门）

原稿是"你挑 2–3 项"，2026-10-30 你拍板 **四项全做、不是选择题**。四项一起塞进一个阶段门会让
"一次交付"变成"半年不出包"，所以拆 **N3a / N3b 两个门**，每门各出一次内测包：

| 序 | 做什么 | 为什么排这个位置 | 判据（进门先写死） |
|---|---|---|---|
| **N3a-1** | **生成即录账本（provenance，A8）** | 必须**先立规矩**：现在生成物走 `execute()` 快照栈、不进事件流；后加的生成（侵蚀层）越多，返工面越大 | 生成一次地形/河流/铺底 → `changeEvents`（或同级 provenance 流）里有对应记录；回放到该日能复现该物；一条 undo 仍能整体撤回 |
| **N3a-2** | **外交表 UI** | 数据层（事件账本 `scenarioEventLedger`）已有，只差视图；**成本最低、见效最快**，放在阶段门开头给足正反馈 | 「某年 A 与 B 什么关系」在界面上点两下就能答；数据只读账本、不新增真源（`test_132` 口径不破） |
| **N3a-3** | **读料桥补全**：提取 → **稳定 ID 绑定**（改名/重画不丢名字）+ 候选导入 | "点图看设定"真正可用的最后一步；和外交表共用同一个"选中实体"入口 | 笔记改名 / 省份重画后，绑定仍在（换 id 不丢名）；候选导入一条 undo；认不出仍进「待人工」，不默认成地点 |
| **N3b-1** | **FMG 侵蚀层** | 生成质量；产出必须走 N3a-1 的账本（顺序不能反） | 海岸有侵蚀/坡面细节（对照样本图）；水位/河网不出现断头；同 seed 一致；8k 格仍 < 1s |
