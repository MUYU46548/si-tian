### 第 7 刀（同日，#13 星域交界：先取证，没动代码）

用户：“星域交界处在给我玩正弦波呢？近就老老实实贴边，隔得远真空没人怪你。还在这重叠呢？”

取证方式：跑 `npm run test:sample-galaxy`，看 `build/sample-galaxy/generated.png`（4 星域的真实出图）。
**结论：不是重叠，是“边缘长瘤”。** 四个星域的边界是**带波瓣的有机形状**（像被噪声推过一圈），
两个相邻星域之间不是一条近似中垂线的干净分界，而是各自鼓出一块、再让出空隙 —— 这就是“正弦波”的观感来源。

归因（读代码得出，未改）：边界来自**所有权场 φ 软融合** + 噪声扰动，噪声振幅相对域半径太大，
于是分界被推成波瓣。要“近贴边、远真空”得把噪声权重压下去、并把融合改成以**距离差**为主
（接近 Voronoi 中垂线），这会改变 `galaxy/domainPaint.js` 与 `factionBorders()` 的取值口径。

**本轮没动**：改边界场会同时影响画布与导出（`test_117` 同源判据），且现有截图工具只覆盖
“航道 LOD / 示例星系”两个机位，没有“两域贴边”的专用机位 —— 又是一个“先补判据再动刀”的场景。
下一轮：先加一张“两域最近点”的固定机位截图，再把噪声权重降下来对比。

**定位到的改点（下一轮从这里开始，别再翻一遍）**：

- `galaxyLayout.js#domainShapes` → `buildFieldInputs()` + `computeDomainShapes()`，**场在 `galaxy/territory.js`**；
  波瓣来自该文件里的扰动项（噪声/抖动），不是 `domainPaint.js`（那个只管描边和标签）。
- 形状走缓存（`shapeKey` 只含布局，不含颜色）→ 调参后缓存键不变，**必须清缓存或改 `GALAXY_LAYOUT.fieldSalt`**，

- 判据：`unit/test_galaxy_layout.js`（e1 等）、`test_116`（覆盖点身份）、`test_117`（画布与导出同源）。

```
wobbleAmp: clamp(claim * 0.26, 30, 88)   →   clamp(claim * 0.10, 12, 34)
```

等值线被推成大波瓣 —— 相邻星域不是一条中垂线，而是一对鼓包。降到 10% 后主体由**距离差**决定，
边界仍有机但不鼓包。

**同类应用怎么做（对照结论）**

| 应用 | 河水怎么来 | 怎么画 |
|---|---|---|
| FMG / Azgaar | Voronoi 格 + flux 累积 | 链 → SVG path，线宽 ∝ √flux，`curveBasis` 平滑 |
| AEG | 同族管线（11 阶段） | Canvas 描边，宽度 = discharge |

| QGIS / GRASS | 流量累积 + Strahler 分级提取 | 按等级/流量定宽 |

我们现在**已与 FMG 同族**（flux + 链 + Catmull-Rom + 宽度渐变）。差的正是参考图里最显眼的一条：
**密度不随气候变**。而我们有现成的降水栅格（`heightmap.prec`），下一步把源头筛选改成
“降水 ≥ 分位 + flux ≥ 分位”，撒哈拉就不会长河。
