## 二、阶段 1：湖泊工具 + 地形特征级锁定

### 湖泊（平底 18/19）

- 单一实现：`utils/heightMath.lakeHeightForWeight(w)` —— `w=1 → 18`（盆底）、`w→0 → 19`（浅缘）。
- 接两处：
  - 剧本底图：`scenarioEditing.applyHeightBrush(..., 'lake')`（`BASEMAP_TOOLS` 新增「湖泊」，
    **Shift+L**，自动切「地形高度」档；一笔 = 一条 undo）；
  - 行星地图：`usePlanetHeightBrush` 的 `brushMode='lake'`（高度面板「湖泊」按钮）。
- 语义：临海挖坑会被海水灌穿成海湾（海拔重标后自然如此），与 SP-1025 / FMG 一致。

### 地形特征级锁定（按坐标）

- 纯函数 `utils/handEdits.js`：`handEditKey` / `mergeHandEdits` / `activeHandEdits` / `reapplyHandEdits`。
- 每次高度/湖泊笔画把**触及格**按世界坐标写进 `heightmap.handEdits`（数组，随 `.sitian` 落盘）；
  **随同一笔 undo 回退**（`applyHeightBrush` 的 undo/redo 各自带 old/new handEdits）。
- 「按轮廓生成地形」重生成时：
  - `activeHandEdits` 先剔掉已被撤销/改回的格；
  - `sameSeed = !prev.genSeed || prev.genSeed === 新种子`：同 seed 按坐标写回；**换 seed = 全新世界，如实丢弃**；
  - 写回发生在气候派生**之前**，所以 temp/prec/biome 会跟着手绘高度重算；
  - 回执写明「已保留 N 格手绘地形」/「换 seed 未保留」。
- 造陆（`generateLandmass`）是「整块新大陆」，**不沿用**手绘锁定（语义上就是新世界）——文档写明。

### 判据

- `scripts/tests/unit/test_hand_edits.js` **5/5**：
  坐标量化 / 合并覆盖 / 撤销后出局 / 同布局全中+换布局 0 / 湖泊只可能 18-19。

  `h18=11, h19=24, hand=35`；重生成 `regenOk=true`、回执「已保留 35 格手绘地形」、
  新图 `hand2=35 / keptH=35`（逐条核对写回值）。
- 全量 **162/162** + **70** 个 Node 单测（本轮最终跑）。
