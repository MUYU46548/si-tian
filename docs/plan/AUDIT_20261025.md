## 六、本轮新增：剧本集（2026-10-25，已落地）

- 数据：`scenario.group`（缺省 = 默认组）+ 项目级 `scenarios.groups: [{id,name,order}]`；
  默认组是虚拟的，旧项目零迁移；组表随项目文件、快照、`scenarios.json` 往返。
- 语义：一组 = 一条独立时间线；左栏 / 时间轴 / 播放 / 切片「全部剧本」都只取当前组；
  卡片墙按「底图 + 剧本集」分别 buildTimeline（否则跨组混排会让岁序/谱系/开局态势错位）。
- UI：左栏剧本集下拉 + 管理对话框（新建/改名/删除/把剧本移组）；新建/编辑剧本可选组；
  卡片墙显示组徽标；切片对话框写明「全部剧本（本组 N 段）」，manifest.scope 带 `groupName`。
- 安全：删除组**不删剧本**（退回默认组）；改组/删组/移组各一条 undo；
  孤儿组 id（剧本引用了、组表没有）在装载/导入/落盘时自动收养，保证剧本不会「无处可见」。
- 用例：`test_146_scenario_groups`（数据层 + 左栏 + 时间轴 + 切片范围 + 删组 undo + 重开项目 + 孤儿组）；
  `unit/test_scenario_groups.js` 7/7。
