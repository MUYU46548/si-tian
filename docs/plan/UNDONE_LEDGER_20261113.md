## 十四、2026-11-14 追加：家具符号按“俯视可见”重画

用户："有的东西很正常，有的像推翻了压在地上，特别是柜子，视角特别奇怪。"

**根因**：第一版把**立面**信息塞进了平面图 —— 柜子画了门缝 + 圆形把手、桌子画了四条腿、
门画了整块实线矩形。从天花板往下看，这些线一条都看不见；画出来就变成"一块板被压扁在地上"。

| 符号 | 之前（立面混进平面） | 现在（俯视可见） |
|---|---|---|
| 柜 / 衣柜 | 双开门缝 + 2 个把手（衣柜还画了挂衣杆） | 柜顶矩形 + 台面内缩边（衣柜多一道柜顶分区线） |
| 桌 | 桌面 + 四条腿点 | 桌面 + 台面内边 + 一条拼接缝 |
| 门 | 整块实线矩形 + 门扇竖线（像门板倒地） | 门扇 + 1/4 开合弧 + **虚线**占位框；弧半径 = 洞口宽（第二版误取 max(w,h)=200，画出巨大弧） |
| 阴影 | 每个小构件继承阴影 → 叠成"几层板压在一起" | 符号内部强制 `shadowBlur=0`，只由调用方在整体上给 |
