## 四、这一轮踩到、值得记住的坑（每条都在代码注释里写清了原因）

| 坑 | 表现 | 根因 |
|---|---|---|
| WebGL 先 `forceContextLoss` 再 `drawImage` | 整张图空白、只剩叠上去的图注纸带 | 上下文丢了，画面一片透明/黑。顺序必须 render → drawImage/toDataURL → dispose |
| 顶点色乘法放在线性空间 | "四档色阶"看着还是一样白 | three 的顶点色是线性量；乘法要在 sRGB 里做（`toneColor` 是先乘再转线性） |
| 路面多边形绕序 | 有路缘线、没有路面 | 平面逆时针 → 世界法向朝下 → 单面材质整块剔掉。绕序统一 + `DoubleSide` |
| 对照图的取景跟着开关变 | 逐像素差从"差一条路"变成"全图都在动" | 取景按**整片数据**算，只有绘制被排障开关筛掉 |
| 屋脊只按"长边" | L 形竖臂也画成横脊（像长屋+方块） | 两臂等宽时竖臂外接矩形长边还是横的；改成"接口方向优先" |
| 备份完整性用字符串长度 | 每份备份都被判"不完整"，写盘中止 | 中文一字符 3 字节，要比 `Buffer.byteLength` |
| 演练与源码编辑同时跑 | 用例集体假红（"内部视图超时"） | Vite HMR 在演练途中整页 reload |

## 六、几个口径（别自己发明）

- **地图单位 = 米**（与区域地图左上角标尺同一口径），建筑内部是 cm；换算只有一处：`SETTLEMENT/MAP_UNIT_CM = 100`。
- **没画内部的建筑照样画成体块**，图注写"N 栋有内部图 · M 栋只有体块"——不许假装它有墙。
- **派生字段只许单向**（`footprint` 这类）：项目里那份是快照，画布/命令算出来的才是真值。
- **改观感必须出图**（像素判据证明不了"变好看了"）；本轮的对照图都在 `build/axonometric/`、
  `build/settlement-axo/`、`build/building-symbol/`（已 gitignore）。
- **提交只 `git add` 明确的文件**：这个仓库有别的会话在并行改（手册），`add -A` 会把别人的活卷进来。

## 七、2026-11-16 晚补的一刀：3D 屋顶按臂拆开

**做了什么**

- `interior/buildShell.js`：屋顶从"墙端点凸包 + 一个最小外接矩形"改成**按占地拆成若干矩形、逐块起四坡**。
  拆分用的是地图符号那一份 `rectDecompose#decomposeFootprint`（同一套顶点、同一套"先看接口再看谁长"的脊向规则）；
  拆不动（斜边 / 曲线墙 / 单块矩形）**一律退回原来的整块路径**，所以矩形楼的出图逐像素不变。
- 顺手把两个共用件抽成独立模块，否则会形成 `buildShell ⇄ buildingSymbol` 的循环 import：
  `interior/polyGeom.js`（凸包 / 最小外接矩形）、`interior/footprint.js`（墙矩形并集 → 占地）。
  旧 import 路径全部保留（`buildingSymbol` 仍 re-export `buildFootprint` / `polygonsOf`）。
- 排障口 `window.__SITIAN_ROOF_SPLIT__ = false`：退回一整块屋顶，**只给出图对照用**。

**判据**

- 单测 `test_building_shell.js` s24~s28：L 形 → 2 块 / 2 条互相垂直的脊（cos 0.00）/ **凹口不落屋面**；
  矩形楼 → 仍 4 面 6 三角、脊高不变；排障口 → 退回 4 面且凹口被盖（这才叫对照）；
  L 形平顶 → 2 顶板 + 2 檐口、凹口不铺；斜边楼 → 退回整块、无 NaN。
- 演练 `drill_axonometric.py` 第 ⑦ 格：页内调**产品同一个** `buildBuildingShell` 读 `stats.roofBlocks`，
  再"关掉拆分 → 动一次屋顶下拉迫使 rebuild → 重出一张"，两张图必须差在屋顶上且四角一致。
  实测：拆开 2 块 / 8 面 / 2 条脊（cos 0.000，脊长 645 与 231）；关掉 0 块 / 4 面；
  逐像素差 **21.12%**，四角 238~238 两边一致。

**这一刀踩的三个坑（都写进代码注释了）**

| 坑 | 表现 | 根因 |
|---|---|---|
| 出檐判据按"整条被接住" | 内转角一片薄三角从对方屋面钻出来 | L 形两臂只用 52% 的边接触 → 判成"没接住"→ 出檐探到邻居地盘上 |
| 想着"顺脊往邻居里延"做天沟 | 延出去那道剖切边悬在空中，比不延更糟 | 两臂坡度略有差别，延出去的面必然在某处高过邻居，裁剪边就露在外面 |
| 测试夹具用了正方形臂 | 脊长算成 0，屋顶退化成攒尖 | 四坡的脊长 = 沿脊长 − 进深；正方形块 + 出檐后进深 > 沿脊长 |

**留下的口径**：共边两侧的屋面都在**檐口标高**接上，屏幕上是一条 V 形谷线 —— 真实屋谷比檐口高一点，
要更真就得算两张屋面的交线（见第五节第 6 项，没做）。
