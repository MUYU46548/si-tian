### 星域总览具体改了什么（对得上原型的哪几条）

| 层 | 旧 | 新（来自 SP-1025 `background.ts` / `nodes.ts` / `labels.ts`） |
|---|---|---|
| 背景 | 径向渐变 + 200 单位坐标网格 + 谐波点子 | 一次生成存资产的「星云 + 深远星系抹痕 + 尘埃带 + 三层星场 + 暗角」，同 seed 恒定 |

| 标签 | 每颗星一块深色圆角底框，远景糊成黑砖 | LOD 门控（远景无名字 / 中景只留枢纽 / 近景全量）+ 贪心避让 + **无底框墨字**（EU4 参考图口径） |

| 星域名 | 势力色圆角底框 + 白字 | 无底框墨字，字色取势力色 |
