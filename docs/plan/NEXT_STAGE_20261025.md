## P0 程序化生成收口（下一轮主战场）

### P0-1 参数模型 + 面板

- 一份纯函数参数模型（`utils/terrainParams.js` 或现有模块扩展）：
  `seed`、`landRatio`、`continentCount`、`plateCount`、`mountainStrength`、`erosion`、
  `latitudeTilt`、`oceanDistance`、`cultureCount`、`religionCount`、`polityCount`。
- 面板：滑块/数字/骰子（换种子）；**预览 → 应用**两段式；应用 = 一条 undo。
- 默认参数与“可复现”规则：同 seed + 同参数 = 同结果（Node 单测）。

### P0-2 造陆（landmass）

- 基于现有 `terrainSynthesis.js` v2（离岸距离场 + priority-flood + 山脉/高原/裂谷）。
- 补“大陆形状”控制：陆块数量/大小/长条/群岛；避免每次都是同一块中央大陆。
- 海岸线：生成后仍走现有“重建海岸线段”，不整省重画。
- 候选：生成 1~3 个候选缩略图，用户选一个再应用；候选有稳定 id，不污染当前底图。
- 验收：同 seed 可复现；应用/撤销逐字节；415 省规模下不冻结（进度 + 可取消）。

### P0-3 气候补全

- 现在 `deriveLayers(heightmap, gridPoints, latitudeFn, oceanDistFn)` 支持纬度/海距，
  但历史剧本调用传的是 `null, null`；补上真实纬度与离岸距离。
- 输出：温度 / 降水 / 群系；画布三档可看；应用一条 undo。
- 验收：同一高度图重复派生结果一致；手动改过的格在“只补空”模式下不被覆盖（策略见 P0-4）。

### P0-4 文化 / 宗教 / 势力派生

暮雨拍板：**自动建势力 + 自动分归属，但永远保留手动编辑能力**。

- 逐格：`culture` / `religion` 网格 + 文化/宗教列表（沿用 `channelBrush` 数据形状）。
- 区域：文化区/宗教区（供势力种子）。
- 势力：按文化区生成种子（名称/颜色可自动，用户可改）；按剧本生成初始归属。
- 再生成策略（必须显式）：
  - 有手改 → 默认**询问**：只补空 / 覆盖 / 取消；
  - 绝不静默覆盖；seed 固定可复现。
- 笔刷保留：文化/宗教/归属笔刷都可覆盖派生结果；一笔一条 undo。
- 验收：派生 → 手改 → 再派生（只补空）不丢手改；覆盖模式有确认；415 省性能达标。

### P0-5 数据与测试

- 新增用例：参数复现、造陆确定性、气候派生、文化/势力派生、手改保护、415 省性能。
- 不变量：生成操作只能改它声称的字段；不能碰剧本/归属之外的数据（test_147 扩展）。

## P1 渲染层接口化

目标：把 ScenarioMap 的“一坨 draw 调用”收成注册表，后续美术/3D 只加层不改 SFC。

- 接口：`{ id, order, when(ctxState), draw(ctx, view), cacheable, quality }`；
  `view = { scale, tx, ty, visibleRect, tier }`。
- 第一张图只接**历史剧本**；行星/区域/建筑不动。
- 质量档：low / medium / high（与现有 `cameraMotion`、LOD 对齐）。
- 验收：重构前后同机位截图逐像素一致（允许抗锯齿差异）；性能不退化；
  `test_100/120/140/145` 全过。

---

## P1 文字层补齐

- 行星 / 区域 / 建筑三处 `fillText` 统一走 `labelStyles` 预设 + `svgTextAttrsFromStyle`；
  导出逐层对拍。
- 重叠避让：优先级（势力名 > 省名 > 城镇名 > 标记名）+ 简单包围盒/网格。
- 样式入口：地名/标记名的全局字号/颜色/描边（现在只能单个改）。
- 自动地名保持默认关闭；需要时勾选。

## P2 小件清欠

- **019 真机验证**：需要一份同名 `.map`；目前只有合成夹具 + 单测，真实 415 省副本未跑。
- **H3**：描轮廓落笔前高亮（影响 N 省预览）、参数浮层化/画布最小尺寸。
- **行星术语**：22 处“星球/行星”口径统一。
- **外交表 UI**：事件账本已有数据，缺关系表界面。
- **奶牛斑块**：找候选 + 滑杆 + 手动确认（不自动删）；先做地形/群系两个视图。
- **test_140**：已绿；若再出现像素类偶发，优先用“整图差”判据，不再赌单点。
