### 施工序

1. **盘点表**：每层「数据字段 → 画布入口 → 导出入口 → 样式来源 → 现有判据」，找双源/缺失。
2. **样式单源**：所有文字层统一走 `labelStyles`（字体/描边/背景条/锁屏字号）；导出由同一份常量生成 SVG 属性（新增 `textStyleToSvgAttrs`）。
3. **可读性**：对比度、字号随缩放、重叠避让（优先级：势力名 > 省名 > 城镇名 > 标记名）、CJK 字重。
4. **导出保真**：PNG/SVG/切片逐层对拍（像素 + 文本内容）。
5. **用例**：一条 CDP「画布截图 vs 导出 PNG 的文本层都能读到」；一条「关掉文字层 → 导出文字像素归零」反向。

### 验收

- 真实 415 省项目导出的 PNG/SVG：省名、势力名、地名、标记名、城镇名都可读，且与画布同内容。
- 任一层改样式只改一处（源码守卫：不允许组件里再写 `font=...` 字面量）。
- 导出与画布逐层对拍通过（允许抗锯齿差异，不允许内容/位置不同）。

## 2. 第二轮：程序化生成收口（含文化/势力派生，笔刷保留）

1. **生成参数面板**：seed / 陆海比 / 起伏 / 山脉走向 / 高原 / 裂谷条数 + 预设；同输入同输出。
2. **造陆**：噪声/板块 → 陆地多边形；复用 `batchSubdivide` 切省；生成可撤销。
3. **气候派生补全**：`deriveAllLayers` 现在把纬度、离海距离传 `null` → 用网格世界坐标补上。
4. **文化/势力/人口派生**：按地形/气候/河流生成文化区、宗教区、势力种子、人口基数；带 seed、可复现；**生成后仍可用现有笔刷逐格改**。
5. （缓）生成物 provenance 进事件账本 —— 等账本 schema 扩展再做。

**验收**：同 seed 两次生成逐字节一致；生成→手改→再生成不静默覆盖手改；文化/势力笔刷仍能覆盖且一条 undo；真实底图全链跑一次（画大陆 → 生成地形 → 自动河流 → 生成文化 → 手动修）。
