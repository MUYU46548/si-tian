## B. 手动（你照着点，5 分钟能过一遍）

### B1. 涂归属一笔：手感 + 落库（对应本轮第 ① 件）

1. 打开 `示例项目.sitian`（**建议先复制一份**，虽然退出保存是正常的，但这是你的孤本）。
2. 顶部“历史剧本”→ 选一个剧本 → 工具选 **“涂归属”** → 在地图上点“势力：”那一行的某个色块。
3. 按住左键在陆地上拖一笔（3~5 格），松手。

**看什么**
- 松手后**立刻**（约 0.1 秒内）状态栏出现“涂归属：N 个省份 → “某某” · 整笔 = 1 条撤销”，颜色当场变；
- 松手后 **1~3 秒内**状态栏出现“已保存”（诚实文案是“已保存到磁盘”，项目态先显示“已保存到项目/等待写入”）；
- 拖的**过程中**不卡顿（每帧几十毫秒的顿挫就是回归）；
- `Ctrl+Z` 一次，整笔（N 个省）一起退回。

> 为什么是 1~3 秒：剧本层 300ms 防抖 + 项目层 800ms 防抖 + 6.5MB 写盘。**这不是 bug**，是设计。
> 实测数字（`npm run test:owner-latency` 的 summary.md）：松手同步段中位 **≈62ms**
> （其中归属写口只有 3.3ms，其余是松手后的同步重绘/回执），松手→磁盘 **≈1.37s**，显式 flush→磁盘 ≈230~250ms。
> 也就是说：**你按下去那一下的顿挫**（62ms）和**数据落库**（1.37s）是两件事，前者是下一轮要砍的。

### B2. 六个浮层：看得清、关得掉（对应第 ③ 件）

进剧本编辑器后逐个点开、再关掉：

| 面板 | 入口 |
|---|---|
| 地形生成参数 | “更多”→ 地形生成参数 |
| FMG 模板地形 | “更多”→ FMG 模板 |
| 造陆 | “更多”→ 造陆 |
| 文化/宗教/势力派生 | “更多”→ 派生 |
| 外交表 | “更多”→ 外交（或“势力：”那一行右侧的“外交”按钮） |
| 地形注记 | **底图编辑模式** → 地形注记 |

**看什么（每个都看）**
1. 面板完整显示在窗口里（四边都不被切）；
2. 面板**盖在画布之上**，能点到面板里的按钮/下拉（点一下“取消/关闭”能关）；
3. 字看得清（深色底 + 浅色字），没有“透明面板糊在画布上”；
4. 关掉之后画布能正常点（不会剩一层看不见的遮罩）；
5. **地形注记只出现一个面板** —— 这条本轮专门修过（之前是两个一模一样的面板精确重叠）。

### B3. 示例星系（测试）：在“自己新建的世界”里跑（对应第 ④ 件）

1. “项目”→ 新建项目（放临时目录，别放知识库里）；
2. 世界观里**新建一个世界**（示例星系只往“当前世界”里追加，没有世界的空项目点按钮会提示“还没有世界”）；
3. 进这个世界的星域视图 → 点 **“示例星系（测试）”**；
4. `Ctrl+Z` 一次。

**看什么**
- 生成后：**4 个星域 + 120 颗恒星 + 航道网**（节点 1 → 125，航道 0 → 175）；
- `Ctrl+Z` 一次精确回到生成前（1 个节点 / 0 航道）；
- 你原来那个项目/知识库**没有任何变化**（这是“自建临时世界”的意义）；
- 按钮叫“示例星系（**测试**）”，悬浮说明里写着“追加进当前世界” —— 它是测试夹具，不是产品生成路径。

## C. 预期现象（看到这些**不是** bug）

| 现象 | 为什么 |
|---|---|
| 涂完到“已保存”要 1~3 秒 | 剧本层 300ms + 项目层 800ms 两层防抖，然后写 6.5MB |
| “示例星系（测试）”会和已有星域叠加 | 刻意的（按钮说明里写了）；要干净样例就按 B3 那样先建空项目/空世界 |
| 示例星系的四个星域大小差很多（5/19/49/3 颗） | 生成参数照抄原型 SP-1025，为了“和原型对照”没调；只影响观感 |
| 国界只在两省相邻处出现，跨海峡/飞地不画 | 国界的定义是“共边两侧归属不同”；海上国界（EU4 那种虚线）没做 |
| 无项目时到处是灰的、按不动 | 只读纪律：没有打开项目 = 不许写 |
| 星域总数 ≥8 时看着还是“摊开的一片”，不像三条旋臂 | 已知未达成（见 STATUS“没做到”第 1 条） |
