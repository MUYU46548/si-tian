## 二、这轮改了什么（每条都有判据）

### A1 势力名字号（用户：「缩小后几乎看不清字」）
- `POLITY_LABEL_STYLE.fontSize 15 → 22`、`PROVINCE_LABEL_STYLE 12 → 15`；
  城镇 `10 → 12`、河名 `10 → 12`、地形注记 `14 → 16`。
- `labelZoom.labelFontScale`：**下限 0.95 → 1.0**（缩小时不再缩字）、上限 `1.55 → 1.75`。
- 判据：`test_159`（far 只剩势力名 / close 出省名+城镇 / 字号系数 1.00→1.19）；
  `unit/test_label_zoom.js` z5；截图 `scenario-fit.png` / `scenario-ratio02.png`。

### A4 省名（用户：「看不到省名，城镇名却可见」）
- 画布**不再跳过占位省名**（与 `isPlaceholderProvinceName` 的注释一致：画布保留、导出过滤）。
- `collectScenarioLabels` 不再互斥：**势力名每一档都画**，省名只在最详档叠加。
- 判据：`test_73`；`test_162` 改为「无归属」隔离（势力名优先级更高，会把形心占走）；
  截图里已能看到「新省份 186」等省名。

### A3/C1 河名、山名折叠
- `drawRiverNameAlongPath`：先量窗口**平直度**（净位移/弧长 < 0.72 或单段转角 > 60° → 退回水平字），
  再用 `placedCharsOverlap` 查**屏幕上**的非相邻字对；`maxTiltDeg 65 → 50`（45° 斜河仍沿河）。
- `drawTerrainLabels`：同一条重叠判据 + `maxTiltDeg 70 → 55`。
- 判据：`test_156`（斜河主轴斜率 0.90 / 水平对照 -0.00，且「太弯有水平退回」）。

### C2 河宽
- `basemapRiverWidthPx` 指数 `0.55 → 0.85`（p50 0.07/0.26：2.82 → 2.31px）；
  导入河逐点因子 `f → f²`（源头 12%、河口满宽）。
- 区间仍守 1.2~4.6px（细河撑得住选中高亮，`test_112/119` 的水面保留率判据不动）。
- 判据：`unit/test_river_coastline.js`（2.31±0.15 / 上下界 / 极细河 1.2~1.6）。

### C3 河流选中（「一堆点点 / 特别难取消」）
- 节点手柄：只在 **河流工具** + **手画河**（`river_`）画；导入河只留两条轮廓线。
- 按下只记候选，**松手位移 ≤4px 才算点选**（拖动 = 平移，不再"随便一拖就选中"）。
- 取消：点空白/城镇/省份、**Esc**、操作栏「取消选中」三条路。
- 判据：`test_112/119/114`（选中轮廓/水面保留率/批量删都不回归）。

### B3 涂了看不见
- 高度笔刷首笔自动切「地形高度」档；群系笔刷自动切「底图编辑」视图；
  文化/宗教笔刷自动切对应「着色」档。
- 行星地形网格同色描边 `cell*0.9` → ≈1.2 屏幕像素（B1 的「莫名其妙的阴影」候选原因）。
- 判据：`test_21/59/69/70/140` 全绿。

### A2/B2 地形名
- 勾上且 `terrainLabels` 为 0 → 直接打开「地形注记」面板并说明「检测山脊 / 手动画一条 → 命名 → 应用」。
- 行星侧「地名」：说明「名字来自地形多边形，笔刷涂的色格没有名字」。
- 判据：`test_157/158/162`（注记的画/存/导出/避让）。

## 三、第三轮：按 EU4 参考图重做（2026-10-27 下午）

> 更正：上一版交接单写「参考图没收到」是**错的** —— 用户的截图与两张 EU4 参考图都在方寸日志里，
> 本轮已逐张看过并按其口径重做。参考图留在 `build/ref/`（临时目录，不入库）。

### 从图里读出的口径（不是猜）

- **EU4 国家名**：大号**墨字**（黑/深褐）、**无底框**、字距很疏、按领土大小分层（马穆鲁克 = 图宽 ~20%，
  小国 3~6%）；省名是小号深字，被国名压住是正常的。
- **EU4 地形**：同一族低饱和色（绿→麦→灰褐），明暗只做很轻的立体；没有纯白山顶/死黑阴影。
- **用户截图里的具体毛病**：① 势力名带深色圆角底框、只有 15px；② 整块大陆是无主省的
  `#4a5568` 深灰蓝 + 个别有主省/湖泊 = "黑一块白一块"；③ 617 个城镇白点糊满全图；
  ④ 高度档 + 阴影是块状死白/死黑；⑤ 省界接头处有 1~3px 的浅色针孔；⑥ 选中手画河时每个节点一个方块。

### 改法

- **势力名**（`polityLabels.POLITY_LABEL_STYLE` + `getLabelPlan` + `useScenarioExport`）：
  去掉底框；`rgba(28,22,15,.88)` 墨字 + 浅米色描边；`letterSpacingEm 0.16`（画布用
  `ctx.letterSpacing`，导出用 `letter-spacing`）；字号按**领土屏幕面积** `sqrt(areaPx)*0.32`，
  下限 20、上限 `地图宽*6%`（绝对 96px）—— 同一套口径画布与导出共用。
  避让：势力名/省名不再被**城市圆点**挡掉（圆点标记为 `soft` 障碍，地形注记走廊仍是硬保留区）；
  视口判定改成「框与视口相交」（边缘的大国名不再整条消失）。
- **省名**与势力名**拆成两个开关**（`showProvinceNames`，`data-testid=toggle-province-names`）：
  旧实现关掉「势力名」会把省名一起关掉——用户排查 A4 时正是被这一点误导。
- **无主省**（`ScenarioMap.getProvinceColor`）：不再刷 `#4a5568`，改为**地形纸色**
  `#d8d2c2` + 群系 28% 淡淡一调；有主省仍是势力色。真实 415 省项目早期年份从"灰蓝大陆"
  变成"纸色大陆 + 有色领土"。
- **城镇点**（`drawBurgs`）：按 `labelZoom` 档位节流 —— far/mid **只留首都**，near 只留人口 ≥20，
  close 全出；点半径 2.5→1.9、alpha .85→.62，首都星 5.5→4.6。
- **地形色带 + 阴影**（`heightmapRaster`）：`HYPSO_LAND` 换成低饱和绿→麦→灰褐（去掉橙/深棕）；
  阴影 `NORM .9→1.15`、区间 `.62~1.08 → .80~1.03` —— 不再出死白/死黑。
- **海岸白斑**：剧本画布的「陆海底色」改为 `landAsSea`（整张底图统一海色，陆地交给省份多边形），
  省界同色描边 1.0→1.6px，堵住平滑后留下的针孔。
- **河流节点**：手画河超过 20 点时**抽稀**画（端点/当前节点必画），手柄 3.2→2.6px。
- 河名折叠/河宽/选河取消等仍是第二轮那套（本轮未改判据）。

### 判据

- `test_159`（档位/字号：势力名 ≥20 且随放大只增不减）、`test_73`（两个开关分开）、
  `test_100`（导出 PNG/SVG 仍有省名与势力色；字号/字距同一套）、`test_160`（地形档色带）、
  `test_156`（河名沿河 0.90 斜率）。
- 视觉：`build/visual-audit/{scenario-fit,scenario-early-unowned,scenario-height-shade,
  planet-fit}.png`（真实 415 省副本）。

### 还没对齐 EU4 的（诚实交代）

1. **字体**：EU4 是手写书法体；我们只能用系统衬线（Georgia/宋体），字形不像。
2. **国土形状内的多行/旋转**：EU4 的巨型国名有时会绕开地形分多行/略旋转；我们仍是单行水平。
3. **地形是手绘纹理**：我们只有 97×45 的高度格，做不到 EU4 那种手绘质感；本轮只把"黑白斑"压掉。
4. **海面**：EU4 有深浅海纹理；我们是海色 + 海深渐变（高度档才有等深线）。
