# 司天 v0.4.0 发布说明（2026-10-25）

本版聚焦「历史剧本」模块的可用性：文字层、底图重导、回归绿。

## 历史剧本文字

- **省名 / 势力名 / 用户地名 / 标记名 / 城镇名 / 河流名**统一走同一份样式；画布与 PNG/SVG 导出同内容、同位置、同颜色。
- 修掉此前「画布浅字、导出深灰」「地名锚点不一致」「标记名位置/颜色不一致」。
- 城镇名/河流名按缩放分级（617 城镇不会糊满图），导出用出版档（首都 + 流量前 12 的河）。
- **新增「图层 → 自动地名」开关，默认关闭**：FMG 导入的城镇/河流名多为英文，不再默认出现在导出图里；需要时勾选。

## 底图重导（019）

- 语义：换新 `.map` = 新底图 + 旧归属迁移；「同一底图只补数据」只限一笔未改。
- 用内容指纹判断「一笔未改」，不依赖保存时间；改过一笔即按新底图处理。
- 重导对话框：旧/新省份数、id 直配、未映射、并省冲突清单、参考图勾选；冲突时阻止写入。
- 旧底图保留归档；整次迁移一条 Ctrl+Z。
- 「刷新底图数据」只给未改过的底图补缺，不再误弹重导。

## 稳定性

- 新增 `test_147` 底图不变量：剧本操作不得改底图几何、高度图、河流、道路、城镇、文化/宗教网格。
- `test_140` 地形笔「将涂格」由偶发假红转为稳定判据（清轨迹后整图逐像素差），单跑 5/5。
- 全量回归：**150/150 通过**（合并前）；本版构建前另跑相关用例。

## 已知边界

- 019 未在真实 415 省项目副本上实跑；目前由合成夹具 + 单元测试覆盖。
- 行星 / 区域 / 建筑文字层按阶段门后延，不在本版范围。
- 安装包未签名，Windows SmartScreen 可能提示「未知发布者」，选择「仍要运行」。
