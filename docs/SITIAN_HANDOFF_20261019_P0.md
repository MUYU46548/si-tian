### 2.1 补上 P0 缺的第三件制图要素：比例尺

`useScenarioExport.buildScenarioSVG()` 新增 `scaleBar`（默认 true）：
- 取全图跨度的 ~22%，收敛到 1/2/5×10^n；
- 左下角画线段 + 两端刻度 + 「比例尺 N 单位」；
- 与标题（左上）、图例（右上）同属一个 SVG，PNG 由同一 SVG 光栅化 → 两处不会不同步。

> 诚实口径：剧本侧没有“真实公里”概念，比例尺标的是**世界单位**；不假装是公里。

## 4. 人测清单（暮雨亲手，P0 终点）

1. 打开你真实的 415 省项目（没有就先从底图建一个）；进入「历史剧本」。
2. 新建/选一个剧本 → 新建一个势力（给个颜色）。
3. 用「涂归属」在图上涂几块（一笔一条撤销；涂错 Ctrl+Z）。
4. 时间轴选一个时间点（比如 2026 年某月某日）。
5. 点导出 PNG（制图版）；打开图片检查：
   - 有**标题**（剧本名 + 日期 + 底图名 + 省数）；
   - 有**图例**（势力色 + 省数）；
   - 有**比例尺**（左下「比例尺 N 单位」）；
   - 涂过的省是势力色，边界/海岸线没被涂改。
6. 把图发回/说一声“过了/哪不对”。这张图就是 v1.9 起一直没闭合的「第一张真图」。

**已知边界**：脚本实测用的是 200 省 `desite.map`，不是你的 415 省真实项目；415 的体量与数据差异只有人测能确认。
