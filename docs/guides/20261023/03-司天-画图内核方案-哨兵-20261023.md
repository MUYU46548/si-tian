# 司天画图内核：为什么连 Windows 画图都不如，怎么救

**性质**：产品级思考（哨兵 2026-10-23，应"帮我想想司天的地图编辑到底要怎么做好"）
**实勘基线**：远端 main 9f981ad（10-19 后零新 push，与"施工缓慢"印证）；本文只做方向与选型，工期以本地实勘为准
**一句话**：Windows 画图赢在**确定性**——光标在哪墨在哪，画歪也是你自己的歪；司天输在**笔迹被翻译吞掉**——画的过程看不到自己的线，拖动中就被翻译成格子/凸包。手抖从来不是问题，**工具对手抖零补偿**才是问题。

> **与全栈 10-23 同题方案（司天-地图编辑手感方案-20261023.md）的关系：互补分工，合一读。** 他修底盘层（基帧缓存/笔刷脏矩形/去重复序列化——596ms 冻结、每帧全量重画），本文修手感层（输入管线 L1-L4）。接缝：本文 L2/L3 的"60fps 跟手渲染"物理依赖他的底盘三件——底盘不补，手感层跑不动。
> 勘误对齐一处：全栈已核"诡异几何"（10525 点海岸线被毁成 22 点，剧本侧数据损毁）10-09 拍板 P2 矢量化后**已修**。本文病根①指的另一件事——AreaMap 涂抹现行仍取凸包（9f981ad 实证，L1765-1767）+拖动中无笔迹反馈，这是显示层语义化设计，不是数据损毁，两案不冲突。

## 一、病根：三个断层（9f981ad 架构级实勘）

**1. 反馈断层（最致命）**
拖动过程中你看到的不是自己的笔迹，而是笔迹被立即翻译成的语义形状——涂抹走凸包（包裹你笔迹的最小凸多边形：你画月牙，它出歪冬瓜；凹处全被填平），地形走格子（26910 格，笔迹被格子分辨率吞掉）。**反馈与预期脱钩，画的人永远不知道会出来什么。**

**2. 补偿断层**
零稳定器、零形状工具、零 Shift 锁定——依赖清单里没有任何手感库。Windows 画图用户手抖也不徒手画：他们用直线工具、形状工具、填充工具。司天只有"徒手涂格子"一条路，等于把手抖用户往墙上逼。

**3. 管线断层**
Chaikin 平滑+抽稀（10-16 新做的 polylineSmooth）质量不错，但只铺到了河流/描线，没铺到全部笔刷；格子吸附、一键撤销这些好基建同样没串成完整手感管线。

> 好消息：三个断层都是**手感层**的病，数据层（结构化引擎/省份/归属）零问题。不需要动 10-18 拍板的手绘路线终判，只需要给它补手感层。

---

## 二、方案：画图内核 = 四层管线

**核心原则一句话：画的过程=笔迹（跟手所见即所得），松手瞬间=语义（预览后落地）。**
Windows 画图的手感和司天的语义，两头都要——翻译不是罪，把翻译暴露在画的过程中才是罪。

> L0 前置=全栈案底盘三件（基帧缓存搬移/笔刷脏矩形/去重复序列化）。L1-L4 全部跑在这上面——他案中的"底盘不补、新笔刷装上照样卡死"警报，对手感层同样成立。

| 层 | 干什么 | 抄谁 | 相对成本 |
|---|---|---|---|
| L1 输入层 | 跟手+滤抖：光标弹簧跟随，手抖被滤掉 | **lazy-brush**（MIT，1385★，专治手抖的稳定器） | 小 |
| L2 显示层 | 所见即所得：拖动中渲染你自己的笔迹，60fps 跟手 | **perfect-freehand**（MIT，5766★，tldraw 同款笔迹引擎，2026-02 仍在维护） | 小 |
| L3 语义层 | 松手才落库：落之前半透明高亮"将涂的格子/将成的区域"，一笔=一条撤销命令 | **自有结构不动**；预览高亮是唯一新交互 | 中 |
| L4 工具层 | 手抖用户的正道：直线（Shift 锁角度）、矩形、椭圆、多段线 | Windows 画图的工具集清单；几何生成 geometry.js 已有大半 | 中 |

**三段式动线**：拖动中=L1+L2（你画的线，歪也是你的歪）；松手前=语义预览（将落的格子高亮闪烁）；松手=一条命令落库（Ctrl+Z 干净回滚）。不满意永远可以重来，重来永远只花一笔的时间。

## 三、手抖三板斧（全部 MIT，协议/活跃度已核验）

1. **lazy-brush 稳定器**——光标不是贴着鼠标走，是弹性的绳子拖着走：小抖动直接吃掉。这是"尽管我手抖"的直接答案。分两档：第一档用 perfect-freehand 自带 streamline 参数（全栈案 Q1 同源，参数级）；手抖重再上 lazy-brush（半径级，强补偿）。
2. **perfect-freehand 笔迹渲染**——压力/速度感知的笔触，tldraw 手感就是它撑的。接入=一个依赖。
3. **工具补偿**——直线/矩形/椭圆/多段线+Shift 锁定。**MS Paint 的本质是"不让你徒手画"，不是"让你徒手画得爽"。**

后置项：形状识别（粗画椭圆→松手变正圆，tldraw 的机制，$1 recognizer 算法 MIT 实现遍地）。锦上添花，排在三板斧之后。

## 五、验收线（你亲自测，过线才算好）

1. 手抖徒手画河 10 条，条条松手即顺滑曲线（不出歪瓜不出锯齿）
2. Shift+拖=笔直直线；椭圆工具=正圆
3. 涂色所见即所得：笔到哪格亮哪格，松手即所得，每一笔 Ctrl+Z 干净回滚
4. **终极测试**：同一张势力图，在司天里画比在 Windows 画图里画更快——因为画图画完改不了归属，司天能。"Windows 画图随便画都比司天好"这句话作废之日，画图内核即验收。
