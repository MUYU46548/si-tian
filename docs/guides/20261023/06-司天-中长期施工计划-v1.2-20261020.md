## 二、交付与施工纪律（本节是铁律，凌驾于一切进度压力）

1. **模块级整包交付**：一个模块从开工到终验一口气做完，中间不设你的检查点。你只在每模块**终验出场一次**。
   - 为什么：分步=会话重开=整个项目状态重灌一遍，几十亿 token 差价真实存在（你 10-20 实证）。这是你 10-12 定调"完成态整包一次到、全程只动一次手"的施工版——当时管交付，现在管施工，一脉相承。
   - agent 侧同理：本地 agent 中途换会话=漂移一次。模块=一个施工会话单位。
2. **一条分支，一次合流**：开一条 feature 分支（如 `feature/history-ledger`）施工，主线全程保持能装能用；合流点=整模块验收线（你终验通过那刻），合回 main+打 tag，一次完成。不再小步合流（10-20 作废）。
3. **每 commit 附一行决策记录**：commit message 首行写清"这步定了什么/为什么"。长会话的老坑是决策点被上下文压缩吃掉——会话真崩了，新会话从 git log 接着干，不用从零读仓库。一次做完的省钱和防翻车，靠这条两全。
4. **文档禁散不禁立**（10-20 晨拍"不新增"→07:30 你改口"自断手脚"）：根因是"散"不是"多"。行账/单点决策第一选择仍是 commit message（第 3 条，不冲突）；成体系的设计/schema/接口知识**允许立档入库**——但一律进 docs/ 对应子目录+根索引一行；归档级文档统一挪 docs/archive/。不再出现第 31 个根目录散件。云侧总纲=本文，不进仓库。
5. **开工先对账**：每模块开工第一动作=对齐远端最新 main（云侧副本最多到 0.3.0/10-13，本地已推进更多），绝不基于旧版本开方。v2.0 〇章"先诊断后开方"纪律继承。
6. **自测隔离三条不变**（v1.9 〇章）：一切自测在整份复制的 .sitian 副本上跑；反向探针（保存重开后数据真变了）；读盘判据（以磁盘实际内容为准，不信界面回显）；无头截图留档（首选 playwright `_electron.launch`）。
7. **验收标准写死一条**：功能存在不算数，你亲手用出来且用着不垃圾才算（10-20 你的实证）。AI 自测全绿只是"可以交给你"的资格线，不是验收线。**本条同样约束云侧记账：agent 报告的"已落地/已落 X"一律不算资产，以你实测为准（10-20 07:30 顶点编辑器实证）。**
8. **问题带原文**：自测修不了的才回来问，带复现步骤+失败输出原文，不许"大概/可能"。
9. **"可抄"断言必须双验**：协议✓+功能实存✓，缺一即幻觉风险（10-20 Azgaar 历史层教训：协议 10-18 就核了，功能存在性没核，三方集体幻觉了一晚）。

### M1 · 历史剧本（当前模块，已选定）

**为什么它先走**：最独立（零外部依赖，10-11 就拍过，不拖资料线）+ 是账本引擎本体（M2/M3 全踩在它肩膀上）+ 笔刷段有现成积木（perfect-freehand，MIT+功能双验过）。注意：v1 所写"有 Azgaar 一整个项目可从头到尾抄"已被 10-20 实勘修正——**Azgaar 可抄的是地图编辑器本体**（.map 序列化不变式、State/Generators/Editors/Renderers 四层分离纪律、40+ 编辑器 mutation 模式），**历史引擎是它的空白区，无抄作业**。

**范围（in）**：
1. **账本引擎（自研，M1 核心）**：事件流 schema 按司天需求设计（world-id+纪元字段第一天就带，多世界/多历法原生）+ 事件按时间排队 + 任意时刻世界状态=回放账本。架构参考=事件溯源（event sourcing，成熟工程范式，事件账本+重放即其核心思想，纯思想参考无版权问题）。Azgaar 只借两个种子：`lore.calendar {year, era, eraShort}` 字段形状 + `campaigns {start, end, name}` 战争事件最小结构（证明轻量时间元数据在 .map 格式有先例，序列化兼容无障碍）。
2. **录入管线**：笔刷涂归属=录事件（"谁哪天把哪个省抢了"直接记账）——笔刷重建与录入是同一件事（perfect-freehand 底座+手感五件：涂色一笔多格/吸管/多选/撤销重做往返/标签联动）。手感轮执行提示词（10-07，自包含照跑）为施工参照。顶点编辑器的去留在本模块施工第一步按"实际画图工作流真用得上"标准裁定。
3. **回放读侧（最小版）**：时间轴拖动到任意时间点→地图=该时刻长相。
4. **导出**：切片导出 PNG/SVG（含标注，图像库读像素验非空白）。
5. **AI 翻译官（可选子件，你点头才启）**：markdown 设定片段→AI 只取本来有的内容→结构化事件草案→你点头入库（10-11 已拍板的草案线，司天侧零开发走现成 .json 导入口）。

**范围（out，显式冻结）**：资料线/Obsidian 桥（M4）、层级链两端、多世界（M5）、外交表/动画（M2）、简易模式裁剪（M3）。

**终验线（你出场一次，三步齐+五件）**：
- 录账（亲手涂几个省的归属/归属变更）→ 拖时间轴（亲眼看地图随年份变化）→ 导切片（导出 PNG 拿去真用）——全程无"地狱感"；
- 笔刷手感五件演示一个不掉链子；
- 415 省真实项目上跑，数据不丢（culture/religion/polityId 语义不丢，写口走 guardWrite）；
- 自测链全绿（副本制+反向探针+读盘+截图）。

**工程量**：三模块中最大（引擎自研+笔刷重建+读侧+导出四件）。**引擎与时间轴两段无抄作业、按自研计**（10-20 实勘口径：预算别按"有现成结构抄来省一大截"的旧乐观口径报）；笔刷段有 perfect-freehand 积木垫底。预估=多条长会话连续施工，你的成本=终验一次+看一行账。换来的自由=事件模型从第一天按你的真实需求长，不用削足适履。
