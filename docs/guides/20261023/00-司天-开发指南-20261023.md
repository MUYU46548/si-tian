### C. 改定义（照旧做会被推倒重来——必须先改再做的项）

**旧任务卡"region 轮廓勾画"（外稿诊断为卡 B 的件）——三处改法**：

## 二、唯一路线（为什么这么排）

**一句话：账本是本体，地图是视图，世界永远在自己硬盘上。** 三面互相锁死=结构性排他；所有编辑都是带 provenance 的事件，任何时刻的世界长相=把账从头放一遍。

工程分期纪律：**先本体，后投影；先写，后读，再演。**
- 写侧（底盘手感+账本+笔刷）=本体与唯一写库入口，最高优先——用户已定调："司天有这个手感就直接发正式版"（2026-10-23，对 vvd 证词）；
- 读侧（读料桥/点图看设定）=紧随其后（账本再好、世界搬不进来=空库；但读侧不挡写侧）；
- 演侧（推演器/时间切面）=远期。

**编辑红线**（用户 10-18 原话钉档）："我依旧希望司天自身保留强大的编辑能力，否则就是看图器。"编辑器是账本的唯一写入侧，命根级，不在"可替换的客户端"之列（可换的只是渲染投影层）。

**反面清单（永不做的三件事）**：不跟 Inkarnate 拼美术笔刷；不跟 World Anvil 拼词条模板；不跟 Foundry VTT 拼跑团会话。**注意**：反面清单约束的是"拼竞争级投入"，不是"不做美术"——美术质感与 3D 都是司天终态目标（第一章 B 栏），只是排在渲染层接口化之后增量叠加。

方向全文见包内 01（战略汇总）。施工序位相对 10-22 三刀序列的变化声明：**读料桥从刀二后移至写侧完成后**（先写后读+用户当前第一痛是画图），**底盘与手感前置插入**（底盘不补、新笔刷装上照样卡死——四方共识）。三刀序列文件被本指南吸收取代。

## 三、施工序列（默认序，六件）

> 原挂起的两个判断题已按保守默认落定（用户 10-23 18:00"直接丢给本地 agent 施工"授权默认值，不同意改一行即可）：

> ② 散布笔冒烟 = **采纳**（L2 笔迹层首落选散布笔，不按 M1 原序在归属笔上磨）。

### 第 0 件 · 对账与留底（开工第一动作，半小时级）

- `git pull` 对齐远端最新 main，git log 确认 HEAD；version 以 package.json 为准（tag 有脱钩史）；
- 415 省 .sitian **整份复制留底**到工作目录外（孤本不可重建，施工前后各一份）；
- 开 feature 分支施工，主线全程保持能装能用；每 commit 首行一行决策记录（"这步定了什么/为什么"——防长会话上下文压缩吃决策点）。

**验收**：git log 本地=远端；备份文件字节数与原件一致；分支已建。

### 第 1 件 · 底盘三件（手感与性能的地基——不补，后面全白做）

干什么（参照包内 02，全部细节在里面）：
1. **搬基帧缓存**：ScenarioMap 的 beginStrokeBase/endStrokeBase 现成模式（已验证 683640 像素差异 0）平移到 PlanetMap / AreaMap / InteriorView——抄**架构**不抄**动作**：每个编辑器都要进这套分层模式；
2. **笔刷进脏矩形**：涂抹/高度/群系/文化/宗教笔刷改局部重绘，不再每帧全量重画；
3. **保存修法②③**：去重复序列化（四次 JSON 深拷贝≈187ms 砍掉）+保存彻底挪出交互主线程。

**验收（真机一测即知）**：连续画 30 秒零帧>50ms（探针现成 `_probe_jank_real.py`）；编辑后保存期间照常拖笔无顿挫。顺路：本件开工前把旧收尾杂项卡里的基线收口动作顺路做完（对照第一章 C 栏处置）。

### 第 2 件 · 散布笔冒烟（B2——手感管线首落+底盘接缝实测，当天可验）

干什么（参照包内 03 四层管线 + 04 四笔接线的散布笔段）：
- 散布笔是四笔中耦合最少的（无格子/无高度场/undo 已对/与账本零耦合），L1-L2 笔迹层先在它身上磨过线再平移；
- **赢 Windows 画图的四条及格线**（判据写死，防"手感"变主观扯皮）：
  1. 按下即出痕（pointerdown 那一刻画布就有第一个墨点）；
  2. 拖动零确认零校验（不弹窗/不要求闭合/不要求落在陆地内——校验全部挪到松手后异步跑，失败只轻提示，绝不回滚笔画）；
  3. 松开即定稿（松手瞬间轮廓与绘制中看到的一致，不出现"画时一个样、松手变个样"）；
  4. 一条 stroke 一条 undo（不是退一个采样点，也不是退整张画布）。
- 量化指标：输入到上屏延迟≤2 帧（慢速绘制单独测）；撒点拖动密度不掉（抖动网格/泊松盘二选一先接——撒点手感的一半来自拖动中不掉密度）；素材实例落笔后可选中可移动，不静默扁平化。

**验收**：四条及格线+量化指标在散布笔上全过=手感管线首落成功+底盘件"笔刷进脏矩形"接缝当场实测（一件验两案）。

### 第 3 件 · 账本引擎（产品本体，纯数据层零 UI 依赖）

干什么（照包内 05 M1 细单步 2-3 原文实现，schema 已定死——**只增不删，不得重新发明**）：
- 事件 schema（worldId/epochId/day/type/groupId/provenance/payload）+ 旧档 baseline 迁移（415 孤本无损升级）+ replay 纯函数 + groupId 事务组 undo/redo（baseline 永不可撤）；

- **笔画对象模型在本件定稿落码**（第一章 C 栏三处改法）：轮廓勾画/地形笔刷/散布笔刷统一输出笔画对象，事件与撤销粒度=用户语义动作。

**验收**：6 项单测全绿 + `src/ledger/` 零渲染层依赖。

### 第 4 件 · 笔刷族总装+时间轴+导出（写侧会师）
