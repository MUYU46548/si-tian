## 一、一句话概况

**司天 = 本地桌面世界观编辑器**（Electron 28 + Vue3 + 原生 Canvas，无外部渲染库）。
事实源有两条：Obsidian 库（Markdown + 前端 YAML）与 `.sitian` 项目文件（JSON 单文件，含实体树 / 剧本 / 地图 / 快照）；
**有项目 → 画布读项目文件；无项目 → 只读浏览知识库，任何写操作被写闸门拒绝**。
「**司天无 LLM**」是身份级边界 —— 它只做数据与编辑，不生成内容。

**当前处在一个明确的转折点上**：地形数据模型刚完成从「手绘多边形」到「高度图驱动」的迁移（A1/A2，2026-09-25），
笔刷族与渲染已补齐（A3/A6/A8 + 2026-10-08 文化宗教笔刷），**编辑能力基本到位；缺的是「把它当工具日常用起来」的最后一公里**。

### 2. 那些「奶牛彩色斑块」是什么

### 3. 画笔模式下不能缩放（已修）
