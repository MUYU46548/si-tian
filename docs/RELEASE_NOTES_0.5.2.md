# 司天 v0.5.2 发布说明（2026-11-05）

> 一句话：**自带一个能直接画画的示例世界**；地图与历史剧本的地形/河网重抄了 FMG 的真实口径；
> 发布物本身补了三道闸（隐私扫描 / 诊断包 / 打包链路真机演练）。

安装包：`sitian-setup-0.5.2.exe`（约 79MB）。不需要 Node、不需要本仓库。

---

## 一、第一次打开就能画

- **示例地图项目**（世界选择页 / 项目面板都有入口）：72 省 · 4 势力 · 两段时代 · 656 条河 · 22,002 格，
  带一棵小实体树（世界 → 行星 → 3 区域）。点一下会把它**复制到“文档/SiTianProjects”再打开** ——
  安装包里的原件是只读的，复制这一份才是你的，可以随便改。
- 没有 Obsidian 知识库也能用：**无知识库 = 也能新建项目**，别被“加载知识库”挡住。
- 无项目时界面是**只读**的（会写明原因与去处）；新建/打开/示例三个入口在任何状态下都在。

## 二、地图与地形

- **河网换成 FMG 真实口径**：每条河带源头 / 河口 / 父河 / 流域 / 等级 / 流量，meander 真的会弯；
  干旱气候下几乎不出河；湖进数据后河在湖岸断、从出口续。孤段（悬空的河）实测 0。
- **地形浮雕底**（EU4 构成比例）+ 海深浅 / 岸线光晕；海岸不再跨海陆混色，最低陆色带改成暖砂。
- **造陆 + 铺底一条命令**（一次 Ctrl+Z 全退）；重生成时**保留手绘地形**（按世界坐标写回，
  面板上有开关和“保留/丢弃多少格”的回执）。
- 修掉一个老坑：重跑造陆会让图幅每次缩 ≈9.5%（省包围盒重推）；现在图幅记进高度图，逐格同网格。

## 三、历史剧本

- **文字层单源**：省名 / 势力名 / 用户地名 / 标记名 / 城镇名 / 河流名走同一份样式；
  画布与 PNG / SVG 导出的内容、位置、颜色一致。
- **剧本分组**（多时间线）：一组 = 一条独立时间线，左栏 / 时间轴 / 播放 / 切片都只取当前组。
- **归属两本账不双写**：`changeEvents` 只记“某省某日归谁”，`timelineEvents` 只记“谁和谁、什么事”；
  v2 迁移把每代的 `initialOwnership + changeEvents` 物化进项目文件。
- 切片导出（逐帧 PNG + frames.json）、外交关系表浮层、标注与标记的增改删（都可撤销）。
- 修掉 2026-11-03 那个“点了没反应”的真根因：六个浮层曾被写在“更多”下拉的子树里，下拉一关整棵树不存在。

## 四、发布质量（这版的重点）

- **隐私与署名扫描**：`code` / `docs` / `root` 三个作用域扫私人专名与私人路径，发布物 0 命中；
  作者署名保留。扫描器自己的词表用 base64 存（否则扫描器就是最大的泄漏点）。
- **诊断包一键导出**：“关于 → 导出诊断包”给出版本 / 运行环境 / 配置摘要（只有“空不空 + 盘符”）/
  最近日志 / 项目计数，**不含世界观正文**，包内绝对路径已脱敏。
- **打包链路真机演练**（`npm run test:packaged`）：核对安装包里的内容（示例在不在、有没有把测试件 /
  真实底图 / 测试 mock 打进去）、安装包内 `app.asar` 与本地构建的 sha256 一致，然后**启动打包版本身**
  真机走一遍：打开示例 → 存一次盘 → 导诊断包。
- 回归：163 个 CDP 用例 + 94 个 Node 单测（见“已知问题 2”）。

## 五、安装

1. 下载 `sitian-setup-0.5.2.exe`，双击安装。
2. **未签名**：Windows 会弹“未知发布者”，这是正常的 —— 点“更多信息 → 仍要运行”。
3. 首次启动没有知识库也能用：直接点“示例地图项目”就能看到能画的地图。

## 六、已知问题（如实写）

1. **未在干净机验证**：发布前跳过了“干净 Windows 装机”演练（时间权衡），所以“装完能不能起”
   只在本机验过。任何安装/启动问题请直接开 issue。
2. **回归里有一条会连坐**：`test_109_self_built_river` 在现在的机器上会挂住渲染进程超过 CDP 的 15s 读超时，
   导致紧随其后的 10 个用例连锁报 `Connection timed out`。这是**判据侧**的问题，不是产品缺陷
   （同一批能力另有 `test_103` / 像素基线守着）。已建卡跟踪。
3. 示例地图右侧岛群有一部分没切成省份（铺底 Voronoi 在岛上覆盖不均），不影响使用。
4. **自动更新**：本版资产名与 `latest.yml` 严格一致（ASCII：`sitian-setup-0.5.2.exe`），
   0.5.2 之后可以自动更新。但 **0.4.0 → 0.5.2 不能自动更新**（0.4.0 的资产名与 `latest.yml` 不匹配，
   当年已知），请手动装这一次。
